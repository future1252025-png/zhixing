# 演示脚本

## 准备

1. 按 [RUNNING_GUIDE.md](RUNNING_GUIDE.md) 启动后端。
2. 网页演示启动 Vite；手机演示安装最新 Debug APK。
3. Android 与电脑局域网调试时，确认手机能够打开后端 `/health` 地址。
4. 开启手机定位权限和 USB 调试（需要安装 APK 时）。

## 推荐流程

1. 注册或登录测试账号。
2. 首页搜索校园地点，拖动和缩放地图。
3. 选择地点并进入地点/教室频道。
4. 点击定位，说明距离过远时只能查看、不能发布。
5. 打开课程表，设置当前学期。
6. 展示 Android 教务系统一键导入，说明导入会覆盖旧课表且个别异常课程不会阻断整批。
7. 切换教学周，检查单双周、教师、地点和节次。
8. 手动新增、编辑并删除一门课程。
9. 进入出发页，以当前位置为起点、下一节课为终点生成建议。
10. 查看路线、出发时间和异常兜底提示。
11. 进入个人中心修改资料并退出登录。

## 讲解重点

- Android 与网页端共享 Vue 业务界面，原生能力由 Capacitor 插件提供。
- 定位来源对用户统一显示为“定位”，不暴露 GPS、北斗或厂商实现细节。
- 教务系统导入保留课程原始信息，路线匹配失败不会影响课表查看。
- 留言为 HTTP 拉取/发布，尚未实现 WebSocket 实时推送。
- 生产地图和 API 需要 HTTPS 与服务端安全配置。

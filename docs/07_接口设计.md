# 07_接口设计：接口设计

## 1. 通用约定

基础路径：

```text
/api
```

请求格式：JSON
响应格式：JSON

登录后请求头：

```text
Authorization: Bearer <token>
```

通用响应：

```json
{
  "code": 0,
  "message": "success",
  "data": {}
}
```

错误响应：

```json
{
  "code": 400,
  "message": "错误信息",
  "data": null
}
```

## 2. 认证接口

### 2.1 注册

```text
POST /api/auth/register
```

请求：

```json
{
  "student_id": "20240001",
  "username": "testuser",
  "password": "123456",
  "nickname": "同学A"
}
```

响应：

```json
{
  "code": 0,
  "message": "register success",
  "data": {
    "id": 1,
    "student_id": "20240001",
    "username": "testuser"
  }
}
```

### 2.2 登录

```text
POST /api/auth/login
```

请求：

```json
{
  "username": "testuser",
  "password": "123456"
}
```

响应：

```json
{
  "code": 0,
  "message": "login success",
  "data": {
    "token": "jwt_token",
    "user": {
      "id": 1,
      "nickname": "同学A",
      "role": "student"
    }
  }
}
```

## 3. 建筑接口

### 3.1 获取建筑列表

```text
GET /api/buildings
```

响应：

```json
{
  "code": 0,
  "message": "success",
  "data": [
    {
      "id": 1,
      "name": "图书馆",
      "type": "图书馆",
      "latitude": 30.0,
      "longitude": 114.0,
      "radius": 80,
      "map_x": 50,
      "map_y": 40
    }
  ]
}
```

### 3.2 获取建筑详情

```text
GET /api/buildings/{building_id}
```

### 3.3 管理员新增建筑

```text
POST /api/admin/buildings
```

### 3.4 管理员修改建筑

```text
PUT /api/admin/buildings/{building_id}
```

### 3.5 管理员删除建筑

```text
DELETE /api/admin/buildings/{building_id}
```

### 4.2 新增建筑频道


## 5. 消息接口

### 5.1 获取建筑消息

```text
GET /api/messages?building_id=1&channel_id=1
```

### 5.2 发送消息

```text
POST /api/messages
```

请求：

```json
{
  "building_id": 1,
  "channel_id": 1,
  "content": "三楼还有空位",
  "latitude": 30.0,
  "longitude": 114.0
}
```

后端必须判断用户是否在建筑半径内。

### 5.3 举报消息

```text
POST /api/reports
```

请求：

```json
{
  "message_id": 1,
  "reason": "广告或骚扰"
}
```

### 5.4 管理员隐藏消息

```text
PUT /api/admin/messages/{message_id}/hide
```

## 6. WebSocket 聊天接口

```text
WS /ws/chat/{building_id}/{channel_id}?token=<jwt_token>
```

消息格式：

```json
{
  "type": "message",
  "content": "一楼人比较少",
  "latitude": 30.0,
  "longitude": 114.0
}
```

广播格式：

```json
{
  "type": "message",
  "data": {
    "sender": "匿名同学",
    "content": "一楼人比较少",
    "created_at": "2026-05-25 12:00:00"
  }
}
```


```json
{
  "building_id": 1,
```

```json
  "longitude": 114.0
```

```json
{

  "message": "success",
```

```json
    "allowed": true,

  }
}
```

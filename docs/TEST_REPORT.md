## 主流程验证

已验证以下 MVP 主流程：

```text
注册 -> 登录 -> 首页建筑列表 -> 建筑详情 -> 建筑留言 -> 课程表 -> 出发建议 -> 静态路径可视化
```

验证结果：

- 注册、登录成功。
- 建筑列表和详情可访问。
- 建筑留言可读取，发布后显示为“匿名同学”。
- 课程可以新增、编辑和删除。
- 删除课程有二次确认。
- 出发建议可以根据当前位置和下一节课生成。
- 出发建议页面显示距离、步行时间、缓冲时间、建议出发时间、状态颜色和静态路径连线。

## 已知限制

- 演示环境没有做逐像素截图验证。
- 第一版不接真实地图 SDK，距离为经纬度直线估算。
- 第一版不接真实 AI API，出发建议为规则算法。
- 第一版不接湖北大学统一身份认证，使用模拟账号 + JWT。
- 第一版留言区为 HTTP 模式，不是 WebSocket 实时聊天。

## 云端检查与剩余风险

首条 GitHub CI 运行：[39231907937](https://github.com/future1252025-png/zhixing/actions/runs/39231907937)。不能把 Pages 构建成功等同于整条 CI 通过。

- 首次前端检查发现 3 条测试断言受运行机器时区影响：测试输入省略 `+08:00`。已修正相关 fixture，并在 UTC 下重新通过全部 572 项及覆盖率门槛；业务使用北京时间的逻辑没有因此放宽。
- 首次云端浏览器回归为 51 passed、3 failed；3 个失败均来自同一个缓存加载用例，其时间处于上课后，却仍期待显示已开始课程。该用例现以课前时间隔离缓存场景，跨越上课时刻的切换仍由独立测试覆盖；修正后本地三种浏览器均通过。Android 云端测试、lint、APK/AAB 编译通过，本轮未安装至手机。
- 后端 `pip-audit` 报告 3 个现有依赖共 20 条安全告警：`httpcore2 2.9.1`、`httpx2 2.9.1`、`PyJWT 2.13.0`。没有禁用或忽略审计来制造通过结果。本轮未升级平板依赖，需要单独安排升级、兼容性回归及线上同步；该清单也不等于已确认每条漏洞在本应用中可利用。
- 前端 `npm audit --audit-level=high` 通过；仍有 3 条中等级开发测试工具依赖告警，涉及 Vitest 链路，不属于浏览器业务包。

## 尚未验证或未实现

- 没有连接 iPhone 真机；移动 WebKit 自动化不是 iPhone Safari 真机验收。本次没有手机蜂窝网络、校园 Wi-Fi 双网络实测，也没有重装 Android App。
- 首版没有 Service Worker 离线能力或后台 Web Push。关闭网页后不能承诺准时提醒；页面保留简明说明，可管理并跨端同步提醒计划。
- 首次发布没有上一条已验证生产版本可用于故障回滚演练；后续部署可在 Pages 保留本次版本作为回退基线。发布和配置回滚不能代替数据库备份。

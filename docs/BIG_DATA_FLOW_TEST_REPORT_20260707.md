## 已发现风险与处理建议

| 风险 | 证据 | 处理建议 |
|---|---|---|
| 登录成本高 | 登录平均 `283.1ms`，P95 `315.35ms` | 登录压测和业务压测分开；业务压测复用 token；生产保留 bcrypt 成本 |
| 热点建筑留言无分页 | 热点建筑一次返回上千条留言 | 已为 `/api/buildings/{id}/messages` 增加 `limit/offset`，默认最新 50 条，最大 100 条 |
| SQLite 并发写存在扩展风险 | 并发测试覆盖 10/20/50 档写入 | 已启用 WAL、`busy_timeout=5000`、外键约束；正式部署仍建议迁移 MySQL/PostgreSQL |
| 原始数据不适合提交 | 原始目录包含数据库和 API 明细 | Git 只提交本脱敏报告，不提交 `.db`、`.jsonl`、token、密码 |

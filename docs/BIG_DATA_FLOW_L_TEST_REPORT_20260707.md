## 观察结果

1. 分页修复有效：在热点留言分布下，留言默认页和第二页 P95 均保持在 `16ms` 以内。
2. 登录仍是最慢接口：登录样本 P95 为 `323.67ms`，符合 bcrypt 密码校验成本预期。
3. 业务接口在 L 档数据量下表现稳定：课程、留言、出发建议、远距离留言拦截均无失败。
4. 原始测试数据保留在本地 `run_data_results`，不建议提交数据库、JSONL 明细或本地日志。
5. 前端留言页已接入 `limit/offset`，支持按页加载更早留言。

## 建议

1. 登录压测和业务接口压测继续分开统计，避免 bcrypt 成本掩盖业务性能。
2. 如果部署到多人真实使用环境，优先迁移 MySQL/PostgreSQL。

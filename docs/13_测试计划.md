# 13_测试计划：测试计划

## 1. 测试目标

验证智行 CampusMind 第一版 MVP 是否满足基本使用要求。

## 2. 测试范围

```text
用户登录
校园地图
建筑详情
建筑聊天室
定位判断
课程表
日程建议
管理员后台
部署访问
```

## 3. 测试用例

## T001 用户注册

测试步骤：

1. 打开注册页。
2. 输入学号、用户名、密码、昵称。
3. 点击注册。

预期结果：

```text
注册成功，跳转登录页或提示注册成功
```

## T002 用户登录

测试步骤：

1. 打开登录页。
2. 输入正确用户名和密码。
3. 点击登录。

预期结果：

```text
登录成功，跳转校园地图首页
```

## T003 地图显示

测试步骤：

1. 登录系统。
2. 进入地图首页。

预期结果：

```text
显示校园地图和建筑点
```

## T004 建筑点击

测试步骤：

1. 在地图上点击图书馆。

预期结果：

```text
进入图书馆详情页
```

## T005 聊天消息查看

测试步骤：

1. 进入建筑聊天室。

预期结果：

```text
显示该建筑历史消息
```

## T006 在范围内发言

测试步骤：

1. 模拟用户坐标在建筑范围内。
2. 发送消息。

预期结果：

```text
消息发送成功，聊天列表出现新消息
```

## T007 不在范围内发言

测试步骤：

1. 模拟用户坐标不在建筑范围内。
2. 尝试发送消息。

预期结果：

```text
发送失败，提示当前不在建筑范围内
```

## T008 课程添加

测试步骤：

1. 打开课程表页面。
2. 添加课程。

预期结果：

```text
课程添加成功，并显示在课程列表中
```

## T009 日程建议

测试步骤：

1. 添加当天后续课程。
2. 打开日程建议页。
3. 获取当前位置。

预期结果：

```text
系统显示下一节课、距离、预计步行时间、建议出发时间
```

## T010 管理员隐藏消息

测试步骤：

1. 使用管理员账号登录。
2. 打开消息管理。
3. 隐藏某条消息。

预期结果：

```text
普通用户不再看到该消息
```

## T011 举报消息

测试步骤：

1. 普通用户进入聊天室。
2. 点击某条消息的举报按钮。
3. 输入举报原因。

预期结果：

```text
举报成功，管理员后台可看到举报记录
```

## T012 部署访问

测试步骤：

1. 部署前后端。
2. 使用公网地址访问。

预期结果：

```text
系统可以正常打开和使用
```

# 14_部署说明：部署说明

## 1. 本地运行

## 1.1 后端运行

进入后端目录：

```bash
cd backend
```

创建虚拟环境：

```bash
python -m venv venv
```

激活虚拟环境：

Windows：

```bash
venv\Scripts\activate
```

macOS / Linux：

```bash
source venv/bin/activate
```

安装依赖：

```bash
pip install -r requirements.txt
```

启动后端：

```bash
uvicorn main:app --reload
```

访问接口文档：

```text
http://127.0.0.1:8000/docs
```

## 1.2 前端运行

进入前端目录：

```bash
cd frontend
```

安装依赖：

```bash
npm install
```

启动前端：

```bash
npm run dev
```

访问：

```text
http://127.0.0.1:5173
```

---

## 2. 服务器部署方案

第一版推荐部署方式：

```text
前端：Nginx 静态部署
后端：Uvicorn / Gunicorn 启动 FastAPI
数据库：SQLite 或 MySQL
```

## 3. 后端生产运行

安装依赖后运行：

```bash
uvicorn main:app --host 0.0.0.0 --port 8000
```

更正式方式：

```bash
gunicorn main:app -w 4 -k uvicorn.workers.UvicornWorker -b 0.0.0.0:8000
```

## 4. 前端打包

```bash
npm run build
```

生成目录：

```text
dist/
```

将 dist 部署到 Nginx 网站根目录。

## 5. Nginx 配置示例

```nginx
server {
    listen 80;
    server_name your-domain.com;

    root /var/www/campusmind/dist;
    index index.html;

    location / {
        try_files $uri $uri/ /index.html;
    }

    location /api/ {
        proxy_pass http://127.0.0.1:8000/api/;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }

    location /ws/ {
        proxy_pass http://127.0.0.1:8000/ws/;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_set_header Host $host;
    }
}
```

## 8. 定位权限说明

浏览器 Geolocation API 在正式环境中通常要求 HTTPS。第一版如果需要部署到公网并使用真实定位，应优先配置 HTTPS；本地开发和演示阶段可以保留模拟定位能力。

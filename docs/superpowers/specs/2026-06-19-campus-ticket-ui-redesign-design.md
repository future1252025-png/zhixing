# 智行 CampusMind 校园出行票据风 UI 设计规格

## 目标

把当前偏通用卡片和渐变的界面重构为具有明确校园出行属性的手机端 H5：用户进入系统后，第一眼看到下一节课、建议出发时间和校园地图，课表、建筑、留言与路线使用同一套视觉语言。

## 视觉定位

- 主题：湖北大学校园出行与日程规划。
- 核心隐喻：路线票据、地图纸、课程时刻表。
- 设计取向：克制、清晰、可操作，不做营销落地页，不堆叠装饰卡片。
- 参考原则：Apple 的层级与留白、WeChat 的移动端熟悉度、Ant 的表单清晰度；不直接复制任何品牌。

## 设计令牌

- 校园墨色 `#17231f`：标题与重要数字。
- 湖大青 `#0b766f`：主操作、起点与当前状态。
- 路线蓝 `#2b6fbe`：地图、链接与路径状态。
- 到站黄 `#f2b84b`：终点、提醒和重点时间。
- 地图纸 `#f3f6f2`：页面底色。
- 分隔线 `#d9e1dc`：表格、列表和输入边界。
- 危险红 `#d94f5c`：删除与迟到状态。

圆角分为 4、6、8px 三档；大型地图和单一主票据可使用 12px。阴影只用于浮动导航、地图搜索和登录票据，常规区块主要依靠留白和分隔线。

## 字体与信息层级

- 中文正文使用 `PingFang SC / Microsoft YaHei / system-ui`。
- 英文与时间数字使用 `Inter / SF Pro Text / system-ui`。
- 页面标题 24-28px，区块标题 17-20px，正文 14-15px，辅助信息 11-13px。
- 时间、距离、周次使用等宽数字特性，避免页面跳动。
- 不使用全大写装饰文案，不使用无意义英文眉题。

## 核心页面

### 登录与启动动画

登录页使用深色路线票据作为主视觉，表单为安静的白色区块。登录成功后 Anime.js 依次完成路线绘制、起终点点亮和下一节课票据信息出现；动画末段触发首页的票据、快捷操作和地图进入，形成连续过渡。支持 `prefers-reduced-motion`。

### 首页

采用已确认的“路线票据优先”布局：

1. 紧凑顶部栏。
2. 下一节课路线票据，显示课程、建筑、时间和建议出发时间。
3. 地图、导入课表、建筑留言三个图标动作入口。
4. 校园地图作为主要内容区，不再重复展示长建筑列表。
5. 空课程状态引导用户导入或新增课程。

### 课表

保留整周一屏布局。顶部使用横向周次切换条，左侧固定时间，课程色块颜色克制且可读。课程点击后使用底部动作菜单编辑或删除，空白单元格保持可点击但不显示“添加”文字。

### 建筑与留言

建筑详情以名称、类型、地图位置和必要说明为主，删除演示性坐标信息。留言页保留聊天气泡，但降低卡片感；定位状态放在输入区附近，返回按钮始终固定可见。

### 出发建议

起点和终点使用搜索选择。生成后先展示深色路线票据，再展示地图路线与距离、步行时间、缓冲时间。正常、紧张、可能迟到通过青、黄、红三种语义色区分。

### 表单、导入和个人中心

表单采用分组行和清晰标签；导入页使用文件投放区、解析进度和课程预览表；个人中心采用账号摘要与普通设置列表，不使用大量装饰卡片。

## 导航与响应式

- 底部导航固定、平整、四个入口稳定，不使用夸张悬浮玻璃胶囊。
- 返回按钮使用粘性顶部栏，在任何滚动位置可见。
- 主要内容宽度在桌面限制为 560px，移动端使用 12-16px 页面边距。
- 320px 宽度下课表、按钮和最长中文词均不得溢出。

## 动效规则

- 登录联动是唯一重点编排动画，时长约 2.2 秒。
- 页面控件只保留 150-240ms 的按压、选中和展开反馈。
- 不使用持续漂浮、光球、随机渐变、背景粒子等装饰动画。
- 地图缩放和路线绘制不被页面动效重复触发。

## 非目标

- 不修改后端接口和业务规则。
- 不重新引入真实 AI、WebSocket 或新地图服务。
- 不把系统改成桌面后台或营销首页。
- 不增加与主流程无关的新功能。

## 验收标准

- 登录、首页、地图、建筑、留言、课表、课程表单、课表导入、出发建议和个人中心视觉一致。
- 前端现有测试全部通过，生产构建通过。
- 后端测试保持通过。
- 地图搜索、课程 CRUD、留言定位、路线生成等现有能力不缺失。
- 主要页面在 375x812 与 430x932 视口中无重叠、溢出和不可达返回按钮。

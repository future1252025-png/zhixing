# 15_验收标准：验收标准

## 1. 基础验收标准

项目完成后，必须满足以下要求。

项目初期建议先按“第一阶段必须”验收主流程，再把 WebSocket、完整管理员后台、举报处理、提醒等作为第二阶段增强项。

| 编号 | 验收项 | 是否必须 |
|---|---|---|
| A001 | 用户可以注册 | 是 |
| A002 | 用户可以登录 | 是 |
| A003 | 登录后可以访问地图首页 | 是 |
| A004 | 未登录不能访问主要页面 | 是 |

## 2. 运行验收

项目必须可以通过以下方式运行。

## 2.1 后端

```bash
cd backend
pip install -r requirements.txt
uvicorn main:app --reload
```

访问：

```text
http://127.0.0.1:8000/docs
```

## 2.2 前端

```bash
cd frontend
npm install
npm run dev
```

访问：

```text
http://127.0.0.1:5173
```

## 4. 最终演示流程

演示时按这个顺序：

```text
1. 打开系统登录页
2. 注册/登录学生账号
3. 进入湖北大学校园地图
4. 点击图书馆
5. 进入图书馆聊天室
6. 模拟在范围内，发送匿名消息
7. 模拟不在范围内，发送失败
8. 添加课程
9. 打开日程建议
10. 查看建议出发时间
11. 管理员登录，隐藏违规消息
```

完成以上流程，即可认为 MVP 合格。

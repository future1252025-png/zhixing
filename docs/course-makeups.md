# 快捷补课（2026-09-15）

## 操作

- 课表周次栏的“补课”：搜索已有课程，或选择“按一天补课”。点击具体课程也可直接“添加补课”。
- 自动带入老师、地点和保存的真实起止时间；只选补课日期即可保存，时间和地点可单独修改。整天补课可取消勾选不需要的课程。
- 默认保留原课；勾选“原日期这几门课停课”时，只取消原日期对应的那一次，不影响其他周。
- 支持同一天改时间：补课日期与原日期可以相同，原时段停课、新时段生效。
- 课表以“补课”标签和实际时间展示。点击补课可修改、取消单次或撤销整批；入口底部也有折叠管理列表。
- 首页、课表、当天课程提醒共用按日期解析的结果。提前量、通知方式沿用课程提醒设置，不增加未来日期的通知。

## 数据与保护

`courses.makeup` 保存日期、原课程 ID、可选停课日期、批次 ID 和原始地点文本；课程名称、老师、地点及时间复制为独立快照。`weeks` 不是补课生效依据。补课按北京时间的准确日期生效，修改学期起始日不会移动日期。

- `POST /api/courses/makeups`：最多 30 门的原子批次，使用 UUID 请求凭证防止重复提交。
- `PUT /api/courses/makeups/{course_id}`：只改这次的日期、时间和可选地点。
- `DELETE /api/courses/{course_id}`：取消一门补课；`DELETE /api/courses/makeups/batches/{batch_id}` 撤销整批。
- 写入、修改、撤销、普通课程编辑和学期调整均检查实际日期冲突，失败回滚。撤销导致原日期与新安排冲突时提示先处理，不静默恢复重叠课程。
- 全量重新导入保留额外补课快照。若有“原日期停课”的调课，先要求撤销相应调课再导入，以免替换原课程 ID 后静默丢失停课规则。不会按课程名称猜测绑定。
- 同一账号最多保留 500 门补课；所有写入和凭证按账号隔离，注销账号时一起删除。

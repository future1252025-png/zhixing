## 使用

- 课程提醒：开关、提前 0–120 分钟、提醒方式。只展示并登记北京时间当天的课程，不预排本周后续或整个学期；直接采用保存的课程时间、上课周次及学期起始日，不采用固定节次推算、不跟随浏览周次。当天缺少准确时间的课不生成通知，界面提示补全。凌晨课程的提前提醒最早为当天零点，文案显示实际提前量。
- 自定义事项：标题、日期、24 小时时间、备注、单次/每天/每周、声音和震动/仅震动/静默通知。重复事项须选结束日期，最长一年；每账号最多 100 个事项。
- 支持编辑、暂停/恢复、删除、完成本次与 10 分钟后再提醒。完成重复事项只跳过该次；修改日期、时间或重复方式会重置完成日期。稍后提醒生成一条独立单次事项。
- 提醒页不再常驻显示设备通知卡片。进入时先检查真实权限，仅未授权时显示可跳过的申请弹窗；点击“开启通知”才申请系统权限。跳过后本次会话不反复提示，主动开启课程提醒或保存事项可再次申请。已有系统授权且未设置过本机偏好时直接启用，明确暂停的选择保持不变。
- 暂停/恢复本机通知、准时提醒、测试通知、重新同步及详细说明集中在“我的 → 通知设置”。调度失败和覆盖数量不足仍在提醒页提示，不因隐藏设置入口而吞掉错误。
- 学期设置只在导入流程及“我的 → 学期设置”中展示；导入成功后隐藏，课表页不常驻显示。旧 `/courses#semester-settings` 书签跳转到新设置页。保存学期仍通过原接口，并通知提醒运行时重新核对当天课程。

## 交付边界

Android 使用 Capacitor Local Notifications，由系统保存并触发本地通知，不依赖平板一直在线。Android 13+ 需要通知权限，准时调度还受“闹钟和提醒”授权控制；没有精确闹钟授权时采用非精确调度并明确提示。勿扰、厂商省电、强行停止及系统空闲调度仍可能影响送达/震动。依据 [Capacitor 官方说明](https://capacitorjs.com/docs/apis/local-notifications) 与 [Android 闹钟说明](https://developer.android.com/develop/background-work/services/alarms/schedule)。

当天课程策略：每天打开一次 App 安排当天通知。页面持续运行跨过北京时间零点会自动切换；从后台恢复时立即更新本机缓存与权限，不等待服务器请求。关闭、强行停止或系统冻结 App 后，不保证后台自动生成新一天课程，需再次打开。自定义事项的未来日期、每日/每周重复规则保持不变。

安卓最多登记最近 400 条未来通知，界面显示数量和覆盖时间；超过时明确提示再次打开 App 续排。此限制避免大量重复事项一次登记过多系统闹钟，不能宣称无限后台调度。

声音/震动/静默分项模式基于 Android 8+ 通知渠道。Android 7 使用系统默认通知方式，页面明确展示此兼容性边界，不承诺旧系统也能逐项静默。

网页同样可以管理、保存和同步规则；在支持通知的安全上下文请求权限，页面运行时按秒检查。关闭网页、浏览器休眠或后台冻结后不保证提醒；本版没有 Web Push 后端。部分移动浏览器不支持页面直接创建系统通知，页面内提示仍可用；震动取决于设备支持。参见 [MDN Notifications API](https://developer.mozilla.org/en-US/docs/Web/API/Notifications_API)。跨标签页通过 Web Locks（支持时）及按账号去重标记减少重复通知；长时间休眠后不补发过时通知。

## 一致性与隐私

- `GET/PUT /api/reminders` 使用登录身份隔离数据，不接受客户端 user_id。PUT 使用 revision 乐观锁与用户写锁；其他设备已更新时返回 409，避免静默覆盖。编辑期间收到更新也要求重新编辑。
- 规则存入服务器并按账号缓存；网络失败只读有效缓存，修改需联网成功保存。另一台设备联网打开 App 后才会更新本机闹钟；不做实时远程撤回的承诺。
- 同账号后台刷新失败保留上次课程快照；离线冷启动缺课表时只保留已登记的当天课程闹钟。旧版本预排的其他日期课程在本机重新协调时取消，兼容旧通知未保存独立日期字段的情况。成功同步后只增删变化的本应用通知。完成/删除会清理对应待触发通知和通知栏旧项，暂停本机或退出登录会取消本应用通知。
- 注销账号通过外键删除服务端提醒记录，并清除当前设备的提醒缓存和通知。提醒不采集精确定位；锁屏详情按系统隐私设置显示。

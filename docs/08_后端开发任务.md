# 08_后端开发任务：后端开发任务

## 1. 后端技术栈

```text
Python 3.10+
FastAPI
Uvicorn
SQLAlchemy
Pydantic
python-jose 或 PyJWT
passlib[bcrypt]
SQLite
WebSocket
```

## 3. 开发顺序

### 阶段 1：项目初始化

任务：

1. 创建 FastAPI 项目。
2. 配置 `requirements.txt`。
3. 配置 SQLite 数据库连接。
4. 配置 CORS。
5. 创建统一响应格式。

验收：

- 运行 `uvicorn main:app --reload` 成功。
- 访问 `/docs` 能看到 Swagger 文档。

---

### 阶段 2：数据库模型

任务：

1. 创建 user 模型。
2. 创建 building 模型。
3. 创建 room_channel 模型。
4. 创建 message 模型。
5. 创建 course 模型。
6. 创建 reminder 模型。
7. 创建 report 模型。
8. 项目启动时自动创建数据表。

验收：

- SQLite 中生成所有表。

---

### 阶段 3：用户认证

任务：

1. 实现密码哈希。
2. 实现 JWT 生成和解析。
3. 实现注册接口。
4. 实现登录接口。
5. 实现获取当前用户依赖函数。
6. 实现管理员权限校验。

验收：

- 可以注册普通用户。
- 可以登录并返回 token。
- 带 token 可以访问受保护接口。

---

### 阶段 4：建筑接口

任务：

1. 获取建筑列表。
2. 获取建筑详情。
3. 管理员新增建筑。
4. 管理员修改建筑。
5. 管理员删除建筑。
6. 初始化若干湖北大学建筑数据。

验收：

- 前端可以拿到建筑列表和地图坐标。

---

### 阶段 5：定位判断

任务：

1. 编写两点距离计算函数。
2. 编写判断是否在建筑半径内的函数。
3. 实现 `/api/location/check`。
4. 发送消息前强制调用或在后端内部判断。

验收：

- 给定用户坐标和建筑 ID，可以返回是否允许发言。

---

### 阶段 6：消息接口

任务：

1. 获取建筑消息。
2. 发送消息。
3. 发送消息时检查定位。
4. 消息前台匿名显示。
5. 后台保存 user_id。
6. 实现基础敏感词过滤。
7. 实现消息举报。
8. 管理员隐藏或删除消息。

验收：

- 在范围内可以发消息。
- 不在范围内不能发消息。

---

### 阶段 7：WebSocket 聊天

项目初期建议先完成 HTTP 消息列表和 HTTP 发送消息，确认消息保存、匿名展示、定位校验、敏感词过滤等规则稳定后，再实现 WebSocket。

任务：

1. 创建 WebSocket 路由。
2. 用户连接时校验 token。
3. 按 building_id + channel_id 管理连接。
4. 收到消息后保存数据库。
5. 广播给当前频道所有在线用户。
6. 断开连接时移除连接。

验收：

- 两个浏览器窗口进入同一聊天室，可以实时看到消息。

---

### 阶段 8：课程表接口

任务：

1. 添加课程。
2. 获取课程列表。
3. 修改课程。
4. 删除课程。
5. 根据星期和时间查找下一节课。

验收：

- 用户可以维护自己的课程表。

---

### 阶段 9：日程规划接口

任务：

1. 获取用户当前位置。
2. 查询下一节课。
3. 获取目标建筑坐标。
4. 计算距离。
5. 计算步行时间。
6. 加入缓冲时间。
7. 返回建议出发时间。
8. 根据聊天室关键词调整缓冲时间。

验收：

- 系统能输出可读的出发建议。

---

### 阶段 10：管理员接口

任务：

1. 建筑管理。
2. 消息管理。
3. 举报处理。
4. 用户查看，可选。

验收：

- 管理员可以隐藏违规消息。

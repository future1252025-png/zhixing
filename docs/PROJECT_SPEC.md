# 智行 CampusMind 项目规格说明

## 1. 项目最终定位

智行 CampusMind 第一版定位为面向湖北大学学生的手机端智慧校园日程规划 H5/PWA。

第一版不是完整智慧校园平台，而是一个 4 周内可完成、可运行、可演示、可写入课程设计文档的 MVP。系统围绕“校园建筑 + 课程表 + 当前位置 + 出发建议”建立核心闭环，帮助学生减少校园信息差，提高日程安排效率。

## 2. 第一版核心价值

第一版只验证一条主线：

```text
登录 -> 浏览校园建筑 -> 查看建筑信息和留言 -> 维护课程表 -> 识别下一节课 -> 选择当前位置 -> 生成出发建议
```

系统需要体现三个课程设计亮点：

1. 以校园建筑为空间入口组织信息。
2. 以课程表和当前位置生成规则化出发建议。
3. 以手机端 H5/PWA 形式完成可演示的校园应用。

## 3. 目标用户

| 用户 | 说明 | 第一版需求 |
|---|---|---|
| 湖北大学学生 | 系统主要用户 | 登录、查看建筑、留言、维护课程、查看出发建议 |
| 演示评审者 | 课程设计验收对象 | 能看懂主流程、功能边界和实现效果 |
| 开发者 | 1 人完成项目 | 范围足够收敛，后端和前端都能在 4 周内完成 |

## 4. 技术路线

| 层级 | 第一版选择 | 原因 |
|---|---|---|
| 前端 | Vue 3 + Vite + Vant UI | 适合手机端 H5，组件成熟，开发效率高 |
| 后端 | FastAPI | Python 友好，接口文档方便，适合个人开发 |
| 数据库 | SQLite | 部署简单，课程演示成本低 |
| 鉴权 | JWT | 满足登录状态维护和接口鉴权 |
| 地图 | 静态建筑点位或卡通地图 | 避免地图 SDK 接入成本 |
| AI | 规则建议 + AI 入口占位 | 保留扩展亮点，不依赖真实 API |

## 5. 交付目标

第一版完成时应具备：

- 可本地运行的前端和后端。
- 可初始化的 SQLite 数据库和演示数据。
- 可在手机浏览器访问的 H5 页面。
- 可展示完整主流程的演示脚本。
- 可写入课程设计报告的功能、架构、数据表、接口和测试材料。

## 6. 项目边界

第一版以“跑通主流程”为准，不追求完整平台能力。WebSocket、真实地图 SDK、真实 AI API、完整管理员后台、学校统一身份认证、室内定位和推送通知均不进入第一版实现范围。

详细范围见：

- `docs/MVP_SCOPE.md`
- `docs/NON_GOALS.md`
- `docs/ARCHITECTURE_OVERVIEW.md`

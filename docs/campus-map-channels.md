# 校园地图与地点频道改造（2026-09-10）

## 交互

首页保留延迟加载的小地图。地图内不再绘制建筑标点、建筑轮廓或透明点击区域，只允许显示用户主动获取的位置及精度圈。点击小地图或“展开地图”进入 `/map`。

展开页使用高德 JS API 2.0 原生标准底图，桌面右侧建筑目录、手机底部独立滚动面板。地图与目录不重叠；地图祖先不使用位移、旋转、缩放入场动画。保留高德商标、审图号和原生控件。

- 原生地点：以 `hotspotclick.id` 查找明确绑定的已有建筑，显示入口卡，再由用户选择频道。
- 未关联地点或普通地图空白点击：仅显示附近建筑候选，需要用户确认；距离近、名称像都不能作为自动进入频道的依据。
- 没有原生标注的建筑：建筑目录、分类或搜索入口；支持“教4 / 4号教学楼 / 第四教学楼”等别名。
- 从频道返回地图，保留本次会话的中心、缩放和选择；数据刷新、连点缩放和定位结果到达不会自动适配整个校园。
- 定位是可选操作，不定位也可浏览频道。设备 GPS/建筑坐标为 WGS84，送入地图时转换一次；地图原生事件为 GCJ-02，不重复转换。
- 地图没有加载完成时先选楼，会在加载后应用这次选择；地图 SDK 请求限时、失败可重试，目录独立可用。

频道页采用紧凑建筑信息、独立公共频道、最近访问教室及可搜索教室列表。留言数量不是在线人数；不虚构活跃状态。沿用既有建筑 ID、教室名和匿名留言功能，不改变发布时的真实位置检查。地图选择点不能用于发言定位认证。

## 地点关系与维护

新增 `building_map_pois`，以 `(provider, poi_id)` 唯一约束，关联 `buildings.id`。同一建筑可关联多个原生地点；一个原生地点不能指向两个建筑。建筑列表和详情返回可选的 `map_pois` 数组，兼容没有该字段的旧前端/后端显示。

已通过实际 AMap PlaceSearch 查询核验 30 处地点，包括教4、图书馆、计算机学院、国际教育学院、双创大楼 A 座等。核验条件：原始名称完全相同且唯一；统一坐标系后距离不超过 15 米，实测约 1 米。不同校区、同名多条、已明显移动的地点均不自动关联。真实点击图书馆标注已验证命中其绑定建筑。

`map_points_seed.json` 保存核验过的 ID。`20260910_11` 迁移冻结这些关系，只关联名称及原始坐标仍吻合的已有建筑；不会重编号、改坐标、创建演示用户或改写历史留言。后续种子导入保留 POI 字段，也保留现存的管理员关联；冲突时拒绝迁移关系，不能静默抢占。

管理员可在未关联原生地点的候选建筑卡中，核对名称后确认关联。接口为 `PUT /api/buildings/{id}/map-pois`，请求 `provider: "amap"`、`poi_id`、`name`。服务端要求已有 `admin` 角色；普通注册始终是学生，不自动提权。重复提交相同关系幂等；同一 POI 改指其他建筑返回 409。

其余建筑仍可从目录进入。不能承诺高德底图上的每段文字都是可点击 POI，也不会为了增加点击区域重新加隐形标点。

## 部署

先备份现有 SQLite 数据库，再同步后端代码和迁移文件，执行：

```sh
cd ~/server/apps/campusmind-backend
.venv/bin/python -m alembic upgrade head
```

然后按现有方式重启后端；不要为本次更新重新运行演示账号播种。迁移之后检查 `/health` 和 `/api/buildings` 中的 `map_pois`。前端与 Android 使用同一 Vue 页面，但 Android 需要重新同步打包安装才能更新。

地图关联表回滚会丢失该表的新增关联，回滚前导出或备份；回滚不删除建筑、课程或留言。

## 验证与边界

自动检查覆盖原生事件与普通点击去重、连续缩放/拖动防误触、位置坐标转换、地图慢加载时选楼、异步销毁、记住视野、管理员权限/冲突、种子保留关系、旧数据库升级和回滚不改历史数据。

浏览器端到端检查涵盖桌面 1440×1000、手机 390×844 的选楼—教室频道—返回地图、目录离线兜底、布局不重叠和 WCAG AA 检查。原生事件契约使用测试替身；另外在真实高德地图上核验了计算机学院和图书馆点击、真实底图显示、零额外建筑 Marker。浏览器手机尺寸检查不等于已完成 Android 真机触控/系统定位验收。

地图位置和视野仅保留在当前进程内，不写本地持久存储，退出账号后清空。最近访问频道仍按账号隔离保存在本机。

# 09_前端开发任务：前端开发任务

## 1. 前端技术栈

```text
Vue 3
Vite
Vue Router
Axios
Pinia，可选
Element Plus 或 Vant，可选
```

如果目标主要是手机端浏览器，建议优先使用 Vant。
如果目标主要是电脑端演示，建议使用 Element Plus。

## 3. 页面清单

## 3.1 登录页 Login.vue

功能：

1. 输入用户名和密码。
2. 调用登录接口。
3. 登录成功保存 token。
4. 跳转地图首页。

## 3.2 注册页 Register.vue

功能：

1. 输入学号、用户名、密码、昵称。
2. 调用注册接口。
3. 注册成功跳转登录页。

## 3.3 地图首页 MapHome.vue

功能：

1. 显示卡通校园地图背景图。
2. 请求建筑列表。
3. 根据 map_x、map_y 渲染建筑点。
4. 点击建筑点跳转建筑详情页。
5. 底部导航进入课程表和日程建议。

建筑点样式建议：

- 小圆点。
- 显示建筑名称。
- 不同类型建筑使用不同图标。

## 3.4 建筑详情页 BuildingDetail.vue

功能：

1. 显示建筑名称、类型、简介。
2. 显示“进入聊天室”按钮。
3. 显示建筑内频道列表。
4. 点击频道进入聊天室。

## 3.5 聊天室页 ChatRoom.vue

功能：

1. 显示建筑名称和频道名称。
2. 显示历史消息。
3. 建立 WebSocket 连接。
4. 获取用户当前位置。
5. 判断是否允许发言。
6. 如果允许发言，显示输入框。
7. 如果不允许发言，显示“当前位置不在建筑范围内，仅可查看”。
8. 消息显示为“匿名同学”。
9. 支持举报消息。

## 3.6 课程表页 CourseTable.vue

功能：

1. 展示用户课程列表。
2. 添加课程。
3. 修改课程。
4. 删除课程。
5. 课程表中选择建筑。

## 3.7 日程建议页 SchedulePlan.vue

功能：

1. 获取当前位置。
2. 请求下一节课建议。
3. 显示课程名称、上课地点、距离、预计步行时间、建议出发时间。
4. 如果没有下一节课，显示暂无课程。

## 3.8 管理员页 Admin.vue

功能：

1. 管理建筑。
2. 查看消息。
3. 隐藏违规消息。
4. 处理举报。

第一版管理员页面可以简化。


## 5. 定位工具函数

前端需要封装：

```javascript
getCurrentLocation()
```

功能：

1. 调用浏览器定位。
2. 成功返回 latitude、longitude。
3. 失败提示用户开启定位权限。

项目初期建议额外提供开发模拟定位能力，方便在非校园环境、本地开发环境或浏览器定位不可用时测试定位发言流程。

## 6. 请求封装

Axios 请求需要自动添加 token：

```text
Authorization: Bearer token
```

如果返回 401，跳转登录页。

## 8. UI 风格

建议风格：

- 清爽校园风。
- 卡片式布局。
- 建筑点可爱化、卡通化。
- 颜色以蓝色、绿色、白色为主。
- 手机端优先，电脑端兼容。

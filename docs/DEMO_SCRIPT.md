# 演示脚本

本文档用于课程设计答辩或项目演示。建议先启动后端和前端，再按以下流程演示。

## 准备工作

1. 启动后端：

   ```powershell
   cd backend
   python -m app.db.seed
   python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
   ```

2. 启动前端：

   ```powershell
   cd frontend
   npm run dev
   ```

3. 打开前端地址，例如：

   ```text
   http://127.0.0.1:5173
   ```

## 演示流程

1. 打开注册页 `/register`，注册一个测试账号。
2. 进入登录页 `/login`，使用刚注册的账号登录。
3. 登录后进入首页 `/home`。
4. 查看校园建筑列表和演示当前位置预设。
5. 点击一个建筑，进入建筑详情页 `/buildings/1`。
6. 查看建筑类型、简介、经纬度、静态地图坐标和步行提示。
7. 点击留言入口，进入 `/buildings/1/messages`。
8. 查看种子留言。
9. 发布一条新留言。
10. 确认留言显示为“匿名同学”。
11. 进入课程表页 `/courses`。
12. 点击“新增课程”，进入 `/courses/new`。
13. 新增一节今天或明天稍后的课程，建筑选择已有教学楼。
14. 返回课程表，确认课程按星期分组显示。
15. 点击编辑，进入 `/courses/{id}/edit`，修改教室或课程名。
16. 返回课程表，确认修改生效。
17. 点击删除课程，展示二次确认弹窗。
18. 进入出发建议页 `/schedule`。
19. 选择当前位置预设，例如图书馆或学生宿舍区。
20. 点击生成出发建议。
21. 展示下一节课、起点、终点、距离、步行时间、缓冲时间、建议出发时间和状态颜色。
22. 展示静态路径连线，说明第一版不接真实地图 SDK，不做真实路线规划。

## 演示讲解重点

- 项目是手机端 H5/PWA，不是原生 App。
- 第一版使用模拟校园账号 + JWT，真实湖北大学统一身份认证作为后续扩展。
- 建筑留言区采用 HTTP 模式，不是 WebSocket 实时聊天。
- 出发建议基于课程表和当前位置规则计算，不使用真实 AI API。

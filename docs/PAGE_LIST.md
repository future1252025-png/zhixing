# 智行 CampusMind 手机端页面清单

## 1. 页面总览

第一版采用手机端 H5/PWA 结构，页面数量控制在 9 到 10 个。

| 页面 | 路由建议 | P0 | 说明 |
|---|---|---|---|
| 登录页 | `/login` | 是 | 用户登录 |
| 注册页 | `/register` | 是 | 用户注册 |
| 首页 | `/home` | 是 | 建筑点位或建筑列表入口 |
| 建筑详情页 | `/buildings/:id` | 是 | 展示建筑信息 |
| 建筑留言页 | `/buildings/:id/messages` | 是 | HTTP 留言区 |
| 课程表页 | `/courses` | 是 | 查看课程列表 |
| 添加课程页 | `/courses/new` | 是 | 新增课程 |
| 编辑课程页 | `/courses/:id/edit` | 是 | 修改课程 |
| 出发建议页 | `/schedule` | 是 | 下一节课和出发建议 |
| 个人中心页 | `/profile` | 可选 | 退出登录、当前位置兜底入口 |

## 2. 底部导航

建议底部导航只保留三个主入口：

| 导航 | 页面 | 理由 |
|---|---|---|
| 首页 | 首页/建筑入口 | 项目主入口 |
| 课程 | 课程表页 | 课程维护高频 |
| 建议 | 出发建议页 | MVP 核心价值 |

个人中心可放在首页右上角或导航内，按时间决定。

## 3. 页面职责

### 3.1 登录页

- 输入用户名或学号。
- 输入密码。
- 提交登录。
- 跳转注册页。

### 3.2 首页

- 展示项目标题。
- 展示静态校园地图或建筑点位列表。
- 提供建筑详情入口。
- 提供进入课程和建议的导航。

### 3.3 建筑详情页

- 展示建筑名称、类型、简介。
- 展示建筑位置说明。
- 提供进入留言区按钮。

### 3.4 建筑留言页

- 展示留言列表。
- 提供留言输入框。
- 发布后刷新列表。

### 3.5 课程表页

- 展示课程列表。
- 支持添加、编辑、删除。
- 课程卡片显示课程名、时间、建筑和教室。

### 3.6 出发建议页

- 展示下一节课。
- 获取或选择当前位置。
- 展示预计距离、步行时间、缓冲时间和建议出发时间。

## 4. 页面设计原则

- 手机端优先，控件使用 Vant UI。
- 每个页面只承担一个主要任务。
- 空状态、加载状态和错误提示必须清晰。
- 演示路径上的页面优先完成，不为低优先级页面做复杂视觉设计。

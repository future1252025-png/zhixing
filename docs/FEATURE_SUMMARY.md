# 当前功能

## 账号与个人中心

- 注册、登录、JWT 鉴权和登录过期处理。
- 昵称、头像等个人资料编辑。
- 受保护页面路由守卫和登录重定向。

## 校园地图与地点频道

- 湖北大学武昌校区真实地图与校园点位。
- 地点搜索、缩放分层、点位选中和步行路线预览。
- 地点名称清洗，移动端优先展示具体名称。
- 地点频道与教室频道匿名留言。
- 用户主动定位和距离校验；距离过远时只允许查看。

## 课程表

- 学期起始日期和总周数设置。
- 课程新增、编辑、删除与完整周课表。
- 教师、地点、节次、单双周和自定义周次展示。
- HTML、Excel 与 Android 教务系统导入。
- 整批导入覆盖旧课表；单条缺失或解析失败不阻断其余课程。
- 课程地点允许保留教务原文，路线需要时再补全地图匹配。

## 出发建议

- 使用当前定位、搜索地点或校园点位作为起点。
- 使用下一节课地点或手动选择地点作为终点。
- 展示课程、时间、缓冲、出发状态和高德步行路线。

## Android

- Capacitor Android App。
- 系统原生定位权限与融合定位。
- 内置湖北大学教务系统登录和课表提取。
- 刘海屏、状态栏、底部手势区和移动端表单适配。

## 质量保障

- pytest 后端回归测试。
- Vitest 前端组件、状态和工具测试。
- Playwright 桌面/手机核心用户旅程。
- Android JUnit 与 APK 构建验证。

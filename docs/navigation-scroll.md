# 页面返回与滚动位置

## 用户行为

- 页面左上角返回、Android 返回键、浏览器后退/前进，恢复相应历史页面的位置。
- 校园、课表、提醒、我的四个主栏目互相切换，继续上次的阅读位置；重复点当前栏目不回到顶部。
- 新打开的详情/设置从顶部开始。首页“本周课表”仍直达真实周次的周次选择区；历史返回该地址时，以离开时的位置为准。
- 地图目录独立保存滚动位置、搜索词、分类及已展开数量；频道列表保存搜索词，提醒保存列表筛选。地图视野仍由地图会话负责。
- 慢加载时等待页面内容和路由转场就绪再恢复，恢复只执行一次。用户主动触摸、滚轮、拖动或按滚动键后立即放弃待执行的恢复，不把用户拉回去。

## 实现约定

原问题是 `scrollBehavior` 在 `out-in` 转场和异步内容完成前恢复，此时页面太短，浏览器把原偏移裁剪到顶部。全局恢复在 `router/index.ts` 和 `utils/routeScroll.ts` 中统一管理，不依赖整页 `KeepAlive`，不会因此让离开的页面持续定位或刷新。

`App.vue` 给页面单根节点附加 `data-route-scroll-key`。新页面有异步内容时，根节点应提供 `data-route-content-ready`，等待完成或失败落地后才设为真。使用独立滚动容器时，提供稳定的 `data-scroll-region` 标识。需要恢复的搜索/列表视图状态，通过根节点 `data-route-view-state` 显式声明；不要放入密码、编辑草稿或服务端数据副本。

只在当前应用内存中保留最近 100 个历史条目及四个主栏目位置，退出/切换账号清空。刷新或重启不保证恢复；页面内容被删除、视口尺寸改变时按新页面可滚动范围落位。新聊天仍定位最新消息；不会为恢复旧位置持久缓存聊天正文或未提交表单。

参考：[Vue Router 滚动行为](https://router.vuejs.org/guide/advanced/scroll-behavior.html)。

## 回归验证

- `src/utils/routeScroll.test.ts`：历史隔离、容量、账号清理、异步与转场等待、手势取消、独立容器。
- `e2e/scroll-restoration.spec.ts`：我的与三个设置入口往返、重复标签、主栏目切换、浏览器前进/后退、慢加载频道与搜索恢复、手势优先。
- `e2e/course-shortcut.spec.ts`：首页真实周快捷入口、浏览周与手动滚动不回弹。
- `e2e/campus-map.spec.ts`：地图目录搜索/展开数量/内部位置恢复，以及原生地点选择和地图视野回归。

端到端用例同时运行桌面和手机尺寸；Android 真机手势及系统返回仍需安装后验收。

# 16_AI编程提示词：给 AI 编程工具的提示词

## 1. 总提示词

```text
你现在是一个全栈开发工程师。请根据我提供的 Markdown 文档开发一个名为“智行 CampusMind”的校园地图与智能日程规划系统。项目采用 Vue 3 + FastAPI + SQLite + WebSocket。请先阅读所有文档，再按阶段生成代码。要求代码简洁、可运行、适合一个人 4 周完成的 MVP，不要实现超出文档范围的复杂功能。
```

## 2. 后端初始化提示词

```text
请先完成 backend 后端项目初始化。技术栈为 FastAPI、SQLAlchemy、SQLite、Pydantic、JWT。请生成完整目录结构、requirements.txt、main.py、database.py、基础配置、CORS 配置，并保证 uvicorn main:app --reload 可以运行。不要写复杂业务，先搭好框架。
```

## 3. 数据库模型提示词

```text
请根据 06_数据库设计.md 为 FastAPI 项目创建 SQLAlchemy 数据模型，包括 user、building、room_channel、message、course、reminder、report 七张表。项目启动时自动创建 SQLite 数据表。请保持字段和文档一致。
```

## 4. 用户认证提示词

```text
请实现用户注册、登录、JWT 鉴权和管理员权限校验。密码必须哈希保存。接口包括 POST /api/auth/register 和 POST /api/auth/login。请同时提供获取当前用户的依赖函数 get_current_user，以及管理员权限依赖函数 require_admin。
```

## 5. 建筑接口提示词

```text
请实现建筑相关接口：GET /api/buildings、GET /api/buildings/{id}、POST /api/admin/buildings、PUT /api/admin/buildings/{id}、DELETE /api/admin/buildings/{id}。管理员接口必须校验管理员权限。请提供初始化建筑数据的方法。
```

## 6. 定位算法提示词

```text
请实现 Haversine 两点距离计算函数，并实现 POST /api/location/check 接口。输入 building_id、latitude、longitude，返回 allowed、distance_meters、radius。判断规则是用户到建筑中心点距离小于等于 radius 则允许发言。
```

## 7. 聊天接口提示词

```text
请实现建筑聊天室功能。接口包括 GET /api/messages?building_id=&channel_id= 和 POST /api/messages。发送消息时必须进行位置判断，不在范围内不能发言。前台显示匿名同学，但数据库保存真实 user_id。请加入基础敏感词过滤和 10 秒 3 条的防刷屏规则。
```

## 8. WebSocket 提示词

```text
请实现 WebSocket 聊天接口 WS /ws/chat/{building_id}/{channel_id}?token=<jwt_token>。连接时校验 token。按 building_id 和 channel_id 管理连接。收到消息后先判断定位、保存数据库，再广播给同一频道所有用户。
```

## 9. 课程表提示词

```text
请实现课程表 CRUD 接口，包括 GET /api/courses、POST /api/courses、PUT /api/courses/{id}、DELETE /api/courses/{id}。课程字段包括 course_name、weekday、start_time、end_time、building_id、room_name、teacher、weeks。
```

## 10. 日程规划提示词

```text
请实现 POST /api/schedule/next 接口。输入用户当前位置 latitude、longitude，后端查询用户当天下一节课，计算当前位置到课程建筑的距离，按 80 米/分钟计算步行时间，默认 5 分钟缓冲，返回建议出发时间和文字说明。如果目标建筑最近消息出现施工、绕路、堵、人多、排队、拥挤等关键词，则增加缓冲时间。
```

## 11. 前端初始化提示词

```text
请创建 Vue 3 + Vite 前端项目，配置 Vue Router 和 Axios。页面包括 Login、Register、MapHome、BuildingDetail、ChatRoom、CourseTable、SchedulePlan、Admin。请先完成基础路由、请求封装、token 保存和登录跳转。
```

## 12. 地图页面提示词

```text
请实现 MapHome.vue。页面显示一张卡通校园地图背景图，调用 GET /api/buildings 获取建筑列表，并根据 map_x、map_y 在地图上渲染建筑点。点击建筑点跳转 /buildings/:id。
```

## 13. 聊天室页面提示词

```text
请实现 ChatRoom.vue。进入页面后获取历史消息，建立 WebSocket 连接，获取浏览器定位并调用位置判断接口。如果 allowed 为 true，允许输入和发送消息；否则禁用输入框，只能查看消息。消息发送时附带 latitude 和 longitude。消息统一显示为匿名同学。
```

## 14. 课程表页面提示词

```text
请实现 CourseTable.vue。支持添加、查看、修改、删除课程。添加课程时可以选择建筑。课程列表按星期和开始时间排序显示。
```

## 15. 日程建议页面提示词

```text
请实现 SchedulePlan.vue。页面获取用户当前位置，调用 POST /api/schedule/next，展示下一节课名称、上课建筑、教室、上课时间、距离、预计步行时间、缓冲时间和建议出发时间。
```

## 16. 管理员页面提示词

```text
请实现简化版 Admin.vue。管理员可以查看建筑列表、新增和修改建筑；可以查看消息列表并隐藏违规消息；可以查看举报列表并处理举报。
```

## 17. 测试修复提示词

```text
请根据 13_测试计划.md 对项目进行测试，逐项检查用户登录、地图显示、建筑点击、聊天室、定位判断、课程表、日程建议、管理员功能。发现问题请直接修改代码，并给出修复说明。
```

## 18. 部署提示词

```text
请根据 14_部署说明.md 为项目生成部署说明，确保后端可以用 uvicorn 启动，前端可以 npm run build 打包，并给出 Nginx 反向代理配置。
```

# 智行 Anime.js 首次打开与登录联动动画设计

## 1. 目标

为智行 CampusMind 增加两段具有连续叙事的品牌动画：浏览器首次使用时播放轻量品牌入场，登录成功后播放完整的“路线票据”动画，并将动画末帧自然衔接到首页下一节课卡片。

动画用于强化“课表、地点与出发建议被连接起来”的产品认知，不改变认证、路由、课程或首页业务逻辑，也不得成为进入系统的阻塞风险。

## 2. 已确认体验

### 2.1 首次打开动画

- 当前浏览器首次使用时播放一次，时长约 0.9 秒。
- 展示智行标记、短路线和“把校园连起来”的品牌文案。
- 使用带版本号的本地标记 `campusmind-launch-intro-seen-v1`。
- 同一版本不重复播放；未来动画有重大变化时通过升级版本号重新展示一次。
- 动画完整播放，不提供跳过按钮。

### 2.2 登录完成动画

- 每次成功登录后播放，时长约 1.8 秒。
- 动画完整播放，不提供跳过按钮。
- 分镜顺序：品牌确认、路线绘制、站点点亮、课程票据上浮、首页票据交接。
- 动画使用真实下一节课快照；无法取得课程时显示“今日路线已接通”的通用内容。
- 动画结束后，背景、路线、黄色终点和票据位置与首页视觉连续，避免独立片头式的突兀切换。

### 2.3 减少动态效果

当系统设置 `prefers-reduced-motion: reduce` 时，两段动画降级为约 0.25 秒的淡入淡出。该无障碍降级优先于“完整播放”的一般规则。

## 3. 视觉语言

- 主背景使用现有深青色路线面板。
- 路线使用青绿色，起点使用主绿色，终点使用黄色强调色。
- 课程信息使用白色票据，并保留黄色左侧识别线。
- 动效使用 Anime.js 时间线完成，缓动以自然减速为主，不使用弹跳、旋转或高频闪烁。
- 动画元素与首页下一节课卡片保持相同的色彩、间距和信息层级。

## 4. 组件结构

### 4.1 `AppLaunchIntro.vue`

负责首次打开动画。组件只接收完成回调，不依赖认证、课程或地图接口。它读取与消费首次打开状态的工作由独立工具函数完成。

### 4.2 `LoginWelcomeIntro.vue`

负责登录完成动画。组件接收可选的课程快照，包括课程名、开始时间、建筑名和教室。没有快照时使用通用票据内容。

组件发出两个事件：

- `handoff`：动画进入首页交接阶段，允许首页容器开始联动。
- `finish`：动画完成或兜底超时，关闭遮罩。

### 4.3 `App.vue`

作为动画调度层，处理以下优先级：

1. 检查并播放首次打开动画。
2. 首次打开动画结束后，再检查登录完成动画标记。
3. 登录完成动画进入交接阶段时，为首页容器添加联动状态。
4. 收到完成事件后卸载动画组件。

同一时间只允许一段全屏动画存在。

### 4.4 动画状态工具

扩展现有 `loginIntro.ts` 或拆分为聚焦的动画状态工具，提供：

- 首次打开标记读取与写入。
- 登录动画待播放标记写入与一次性消费。
- 课程快照序列化、读取和消费。

课程快照使用 `sessionStorage`，读取后立即清除，不作为课程数据源。

## 5. 数据流

### 5.1 首次打开

1. 应用挂载。
2. 调度层检查版本化首次打开标记。
3. 未播放时显示 `AppLaunchIntro`，同时写入已播放标记。
4. 动画完成后进入当前路由页面。

### 5.2 登录成功

1. 登录接口成功并保存 JWT。
2. 尝试读取当前用户课程并计算下一节课。
3. 将可用课程信息写入一次性动画快照；失败时仅写入待播放标记。
4. 跳转首页或原始受保护目标页面。
5. `App.vue` 消费标记并播放 `LoginWelcomeIntro`。
6. 动画末段触发 `handoff`，首页容器同步进入。
7. 动画完成后清理遮罩与临时状态。

课程快照预取失败不得导致登录失败，也不得改变导航结果。

## 6. 动画时间线

### 6.1 首次打开，约 900ms

- 0-220ms：品牌标记与名称淡入。
- 180-650ms：短路线绘制，起终点依次点亮。
- 560-900ms：品牌文案出现并整体淡出进入页面。

### 6.2 登录完成，约 1800ms

- 0-260ms：品牌确认。
- 260-920ms：路线绘制与站点点亮。
- 920-1450ms：课程票据上浮，显示下一节课或通用状态。
- 1450-1800ms：票据向首页卡片位置过渡，动画遮罩淡出。

## 7. 稳定性与异常处理

- 每段 Anime.js 时间线均设置完成回调和独立兜底计时器。
- 登录动画最长 2.4 秒后必须关闭；首次打开动画最长 1.4 秒后必须关闭。
- 组件卸载时撤销时间线并清理全部计时器。
- 动画初始化失败、DOM 引用缺失或课程快照格式错误时直接执行完成流程。
- 动画不持有 JWT，不修改认证状态，不阻止路由守卫执行。
- 页面隐藏或快速路由切换时仍需可靠清理动画资源。

## 8. 测试与验收

### 8.1 自动测试

- 首次打开标记仅在同一版本首次返回待播放。
- 登录动画标记和课程快照读取后立即清除。
- 非法课程快照安全降级为空值。
- 登录成功时课程预取失败仍能跳转。
- 原有认证、路由、课程与首页工具测试继续通过。
- `npm test` 与 `npm run build` 必须通过。

### 8.2 人工验收

- 清除本地存储后首次打开应用，品牌短动画只播放一次。
- 刷新页面，首次打开动画不重复播放。
- 登录有后续课程的账号，动画票据显示对应课程信息并衔接首页。
- 登录没有后续课程的账号，显示通用票据并正常进入首页。
- 开启系统减少动态效果后，动画明显缩短且页面仍可正常使用。
- 动画播放期间不出现白屏、闪烁、重复遮罩或首页布局跳动。

## 9. 范围边界

本次不增加启动广告、音效、视频素材、手势跳过、复杂 3D 动画或后端接口；不修改认证协议、课程计算规则、首页地图和其他业务功能。

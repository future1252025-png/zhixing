# 湖大智行 CampusMind 文档包

这是一个用于交给 AI 编程工具执行的项目文档包。

## 项目简介

湖大智行 CampusMind 是一个面向湖北大学学生的校园地图与智能日程规划系统，核心功能包括：

- 卡通化校园地图
- 建筑级位置聊天室
- 匿名发言
- 位置验证后发言
- 课程表管理
- 路线时间规划
- 出发提醒
- 管理员审核

## 推荐技术栈

```text
前端：Vue 3 + Vite
后端：FastAPI
数据库：SQLite
实时聊天：WebSocket
认证：JWT
定位：浏览器 Geolocation API
```

## 使用方式

将整个文档包交给 AI 编程工具，让它先阅读 `01_AI执行总说明.md`，然后按文档顺序逐步生成项目代码。

建议不要一次性让 AI 生成完整项目，而是按阶段执行：

```text
1. 后端初始化
2. 数据库模型
3. 用户认证
4. 建筑接口与初始建筑数据
5. 定位判断
6. HTTP 聊天接口
7. 课程表
8. 日程规划
9. 前端主流程页面
10. 管理员最小功能
11. WebSocket、举报、提醒等增强功能
12. 测试部署
```

# 01_AI执行总说明：交给 AI 执行的总说明

## 1. 项目名称

智行 CampusMind

## 2. 项目一句话说明

面向湖北大学学生的校园地图化日程规划系统，提供卡通化校园地图、建筑级位置聊天室、课程表管理、路线时间规划和出发提醒功能。

## 3. 执行目标

请 AI 按照本文件夹中的 Markdown 文档完成一个可运行的 MVP 项目。项目采用前后端分离架构：

- 前端：Vue 3 + Vite
- 后端：Python FastAPI
- 数据库：SQLite，后续可迁移 MySQL
- 实时聊天：WebSocket
- 登录鉴权：JWT
- 地图：卡通化校园底图 + 建筑坐标点
- 定位：浏览器 Geolocation API + 建筑半径判断

## 4. 开发原则

1. 优先完成可运行 MVP，不追求复杂功能。
2. 代码要简洁、清晰、可维护。
3. 每完成一个模块都要保证可以运行和测试。
4. 不要引入过多复杂依赖。
5. 第一版不接入真实湖北大学统一身份认证，用模拟学号登录。
6. 第一版不做真实室内定位，只做建筑级定位。
7. 第一版不接入真正 AI 大模型，用规则算法完成日程建议。
8. 前台匿名，后台保留 user_id 便于管理。

## 6. 最终交付物

请最终生成以下内容：

```text
campusmind/
├── backend/
├── frontend/
├── docs/
└── 00_文档目录与使用说明.md
```

项目必须支持：

1. 用户注册、登录。
2. 地图首页展示湖北大学建筑点。
3. 点击建筑进入建筑详情页。
4. 每个建筑有匿名聊天室。
5. 系统能根据当前位置判断是否允许发言。
6. 用户可以添加课程表。
7. 系统能计算下一节课的建议出发时间。
8. 管理员可以管理建筑和消息。
9. 项目可以本地运行。

## 7. 建议执行方式

不要一次性生成全部代码。建议按阶段执行：

```text
阶段1：搭建后端项目与数据库
阶段2：完成用户、建筑、课程、消息接口
阶段3：完成定位判断、HTTP 聊天和课程日程接口
阶段4：搭建前端项目与页面路由
阶段5：完成地图、建筑、聊天室页面
阶段6：完成课程表和日程建议页面
阶段7：完成管理员最小功能
阶段8：补充 WebSocket、举报、提醒等增强功能
阶段9：测试、修复、部署
```

## 8. 当前限制

- 个人开发者，4 周完成。
- 开发者主要熟悉 Python，后端基础较弱。
- 项目目标是可上线 MVP，不是完整智慧校园系统。
- 暂不接入学校真实统一身份认证。
- 暂不实现真实室内地图和楼层定位。

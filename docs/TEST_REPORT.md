## 主流程验证

已验证以下核心流程：

```text
注册 -> 登录 -> 首页校园地图 -> 建筑详情 -> 聊天室选择 -> 建筑/教室留言 -> 课程表 -> HTML/Excel 导入 -> 出发建议 -> 高德路线预览 -> 个人资料编辑
```

验证结果：

- 注册、登录和 token 续期逻辑可用。
- 首页地图可以加载校园点位，支持地点搜索和点击建筑。
- 建筑详情可以进入聊天室选择页。
- 建筑总频道和具体教室频道可以查看留言。
- 用户定位不满足要求时，留言输入框被禁用并显示中文提示。
- 课程可以新增、编辑、删除。
- 课程表支持周次筛选，能够显示当周课程。
- HTML/Excel 课表导入可以解析课程并预览。
- 出发建议支持起点和终点搜索，终点不选时可以使用下一节课地点。
- 地图路线预览可用；高德路线失败时不阻断页面主流程。
- 个人中心支持昵称和头像编辑。

## 已知限制

- 当前账号体系为项目内账号 + JWT，未接入湖北大学统一身份认证。
- 留言为 HTTP 模式，不是 WebSocket 实时广播。
- 地图与路线能力依赖高德 Web 端 JS API Key、安全密钥、浏览器定位权限和网络环境。
- SQLite 适合本地演示和课程设计，生产环境建议迁移到 PostgreSQL 或 MySQL。

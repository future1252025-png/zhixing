# 演示脚本

本文档用于课程设计答辩或项目演示。建议先启动后端和前端，再按以下流程演示。

## 准备工作

1. 启动后端：

   ```powershell
   cd backend
   python -m app.db.seed
   python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
   ```

2. 启动前端：

   ```powershell
   cd frontend
   npm run dev
   ```

3. 打开前端地址，例如：

   ```text
   http://127.0.0.1:5173
   ```

## 演示流程

1. 打开注册页 `/register`，注册一个测试账号。
2. 进入登录页 `/login`，使用刚注册的账号登录。
3. 登录后进入首页 `/home`。
4. 查看真实校园地图、地点搜索和校园点位。
5. 点击一个建筑，进入建筑详情页 `/buildings/1`。
6. 查看建筑类型、简介、地图位置和步行提示。
7. 点击聊天室入口，进入建筑聊天室选择页。
8. 选择地点频道或具体教室频道。
9. 查看历史留言。
10. 获取定位；如果距离目标建筑过远，展示输入框禁用状态。
11. 在允许发言时发布一条新留言。
12. 确认留言显示为“匿名同学”。
13. 进入课程表页 `/courses`。
14. 展示整周课表和周次切换。
15. 进入 HTML/Excel 导入页，上传课表并查看预览。
16. 手动新增或编辑一节课程，确认建筑可自动匹配。
17. 返回课程表，确认课程显示在对应周次和时间格。
18. 点击课程，展示编辑/删除操作。
19. 删除课程时展示二次确认弹窗。
20. 进入出发建议页 `/schedule`。
21. 搜索或选择起点；终点不选时使用下一节课地点。
22. 点击生成出发建议。
23. 展示下一节课、起点、终点、步行时间、缓冲时间、建议出发时间和状态颜色。
24. 展示高德地图路线预览，并说明路线失败时系统会保留可理解的兜底提示。

## 演示讲解重点

- 项目是手机端 H5/PWA，不是原生 App。
- 第一版使用模拟校园账号 + JWT，真实湖北大学统一身份认证作为后续扩展。
- 建筑/教室留言区采用 HTTP 模式，不是 WebSocket 实时聊天。
- 出发建议基于课程表和当前位置规则计算，不使用真实 AI API。
- 当前版本已接入高德地图 JS API，地图能力依赖有效 Key、网络和浏览器权限。

# 智行 / CampusMind 前端优化与美化方案

> 日期：2026-07-26　　范围：`frontend/` 全站　　定位：**在现有「清新自然」设计语言基础上收敛与打磨，不推倒重来**

本方案基于一次覆盖 5 个域（设计系统 / 认证个人 / 课程课表 / 地图消息 / 历史脉络）的 UI/UX 全量调研。调研结论一致：现有前端**远高于「工程师默认样式」水准**——有成套设计令牌、自绘胶囊 Tabbar、成熟的键盘避让、无障碍与 `prefers-reduced-motion` 覆盖、双移动视口 + 对比度 e2e 门槛。真正的问题不在"缺设计"，而在**设计事实来源分裂、令牌落地不彻底、核心页面几处硬伤、动效体系有始无终**。因此本方案的主线是"收敛地基 → 打磨核心页 → 统一动效 → 沉淀组件"。

---

## 一、设计北极星（延续，不改方向）

沿用 7.18「清新动感 / 清新自然」方向，明确其定义供全站对齐：

- **色彩**：暖纸底（`#f4f6ef` / `#fffdf8`）+ 左上阳光黄 / 右上青绿双 radial 渐晕；自然系调色板——主绿 `#4f7d58`、深绿 `#355f40`、叶绿 `#87a878`、薄雾蓝 `#6f9faa`、阳光 `#f2c86f`、蜜桃 `#e99b7d`、丁香紫 `#b7a7c8`；危险色柔化 `#c96f66`；仅浅色模式。
- **形状**：大圆角（26 / 17px）、绿调柔和阴影、发丝级绿描边、有机叶形装饰点。
- **字体**：正文 HarmonyOS Sans SC / MiSans / PingFang；大标题楷体气质；`tabular-nums`；正文下限 12px；触控下限 44px。
- **动效（"动感"来源）**：弹簧缓动 `cubic-bezier(0.16, 1, 0.3, 1)`；滚动进场 `v-reveal`；全局 `prefers-reduced-motion` 降级。

这条方向已被 hardening spec §16 排入后续阶段（"地图与社区" + "全站体验"），本方案即沿该既定路线落地，不引入新决策争议。

## 二、当前主要问题（按杠杆排序）

### 根因级（横切多页，最高杠杆）
1. **三份平行的设计令牌事实来源**：`base.css :root`（旧票据风令牌，被静默遮蔽）、`fresh.css :root`（现行）、`App.vue` themeVars（硬编码第三份 hex）。改一处色就漂移，是所有视觉不一致的总根。
2. **令牌"有而不用"**：pages/components 中硬编码 hex **约 517 处**，圆角字面量 20+ 种，字号令牌几乎不被引用。尤其十几个近似绿（`#e5eee0`/`#edf5e8`/`#eaf2e6`…）和 5 种"主绿按钮"并存，肉眼可辨的品牌漂移。
3. **楷体标题在 Android 上失效**：无 `@font-face`，STKaiti/KaiTi 在学生主力机型上回退黑体，"手写感"品牌人格在最大目标平台上不成立。
4. **容器宽度失控**：Tabbar 560 / `.page-content` 580 / `.van-nav-bar` 600 三层壳不一致，页面级又各自为政（470~980），平板/横屏错位。
5. **顶部安全区零处理**：`env(safe-area-inset-top)` 全库未用，配合 `viewport-fit=cover` 在刘海屏/PWA 独立模式下导航栏顶进状态栏。
6. **死代码 CSS**：`base.css` 的 `login-handoff` 块 + hero/metric/pill 未用组件类（引用的 7 个类已不存在）。（`RealCampusMap.vue` 的旧霓虹主题约 527 行死 CSS 已在本轮修复中清除。）
7. **动效体系三套并存 + animejs 有始无终**：HomePage 用 animejs、其余页用 `v-reveal`、欢迎卡用裸 CSS keyframes；animejs 整个库只剩一处 `stagger` 调用，配套 143 行 spec 与孤儿代码（`shouldPlayAppLaunchIntro`、handoff CSS）空转。路由转场 `out-in` 双 560ms（体感 1.1s）是全站最大单点延迟，且无前进/后退方向感。

### 页面级高优
- **课表（CoursesPage，核心页）**：① 色块算法用均分色环 HSL，饱和过高破坏自然色系，且每增删课全部颜色重排、"颜色=科目"记忆被打断；② 吸顶表头 `top` 用 46px 而实际导航 58px，滚动被盖住 12px 出脏边；③ 同格双课（单双周并存）`min-height:164px` 叠加把整行撑到 ~340px 爆行；④ 空白格"＋"新增入口 `opacity:0`，触屏完全不可见；⑤ 零课程空状态是全域最差（默认 `van-empty` 灰图），且没放"导入课表"这个更高效路径。
- **地图 / 消息**：① 非选中建筑只有透明命中区、无可见 pin，用户只能靠底图 POI 猜哪里能点，且低 zoom 命中区仅 10px；② 消息页**双层滚动**（页面 + `.message-list` 内 `max-height` 内滚），聊天流被截成嵌套小窗；③ "看更早留言" prepend 后无 `scrollTop` 补偿，视口跳动丢失阅读位置；④ 作者色点用列表 index 派生，prepend 后全体作者变色。
- **认证 / 个人**：① 会话过期被踢回登录页**零解释**（`reason=expired` 传了但从不消费）；② 登录按钮转圈被过场预取（串行 `fetchSemester → getCourses`）拉长 1-2s，只为首页一张 2.8s 卡片；③ 过场欢迎卡收尾粗糙——定时移除后高度瞬塌，首页内容上跳 ~90px，且不可点按跳转；④ 个人页 hero footer 是硬编码假统计（与账号列表重复），是全域最像占位的区块；⑤ 密码框无小眼睛切换、无"忘记密码"占位。

### 其余（中低）
术语不统一（地点频道 / 教室频道 / 建筑总聊三种叫法）、返回全用 `router.push` 撑爆历史栈、三套建筑选择控件、9~11px 击穿 12px 字号下限、非标字重（720/760/680…被就近吸附成假精度）、双图标语言（自绘 TechIcon + 16 种 van-icon）、首页两套搜索、地图错误文案暴露开发者信息（"检查高德 Key/白名单"）等。

## 三、分阶段实施方案

> 每阶段自成一个可交付、可回归的批次。**阶段 0 是所有视觉批次的地基，必须先做**——否则后续每处美化都在分裂的令牌上打补丁。全程延续 hardening 的验收门槛：双视口（390×844 / 430×932）Playwright e2e + 文字对比度 4.5:1 断言。

### 阶段 0 · 设计系统地基收敛（前置，最高杠杆）

目标：让"改一个色 / 一个圆角"只需改一处。

| 任务 | 做法 | 涉及文件 |
|---|---|---|
| **令牌单一来源** | 合并为 `tokens.css`（`:root` 只留一套终值：色板 + soft 变体 + 间距档 4/8/12/16/24 + 圆角档 sm14/md18/lg26/pill + 字号 + 阴影 + 缓动）+ `vant-overrides.css`。删除 `base.css` 被遮蔽的旧令牌、Inter 字体栈、死代码块。 | `styles/base.css`→拆分, `styles/fresh.css`, `main.ts` |
| **themeVars 去重** | `App.vue` 的 ConfigProvider themeVars 改为从单一 TS 常量表（`styles/tokens.ts`）生成，与 CSS 变量同源，根治 JS/CSS 值漂移。 | `App.vue`, 新增 `styles/tokens.ts` |
| **硬编码 codemod** | 对 517 处 hex + 20+ 圆角字面量做一次性收编：近似绿归并到 3-4 个 surface token，5 种"主绿按钮"统一到 `--fresh-green`/`--fresh-green-dark`。 | `pages/*.vue`, `components/**` |
| **壳层宽度统一** | 单一 `--page-max: 600px`，nav-bar / page-content / tabbar 三层共用；宽页面（导入 / 采集）显式 opt-out。 | `styles/*`, `AppTabbar.vue` |
| **顶部安全区闭环** | 导航栏 `padding-top: env(safe-area-inset-top)`，校验 PWA `status-bar-style`。 | `styles/*`, `index.html` |
| **品牌字体上线** | 楷体标题子集化打包 woff2（如霞鹜文楷 LXGW WenKai，仅子集标题用字 + 数字，约几 KB），`@font-face` + `font-display:swap`；保证 Android 手写感不塌方。**这是三页共享的最高杠杆视觉修复。** | 新增 `assets/fonts/`, `styles/tokens.css` |
| **字重规整** | 非标字重（760/750/680…）就近归到 400/500/600/700 标准档，消除假精度。 | 全 `styles` + pages |

验收：全站视觉零回归（e2e 截图对比）；`grep` 硬编码 hex 数量下降 90%+；改主色单点生效。

### 阶段 1 · 核心页面美化（课表 + 地图/消息，用户高频）

**课表 CoursesPage**（改动集中、体感提升最大）：
- 色块建**固定策展调色板**：从令牌派生 8-10 个低饱和自然色，按课程名**哈希**取色（替代均分色环）→ 跨周 / 跨会话稳定，天然融入设计语言。仅改 `utils/course.ts` 的 `buildCourseColorMap`，消费端 `--course-accent` 机制不动。
- 行高从固定 `minmax(170px,1fr)` 改**按内容自适应** `minmax(96px,auto)` + 删 `.course-content` 的 `min-height:164px` → 一并修复同格双课爆行 + 稀疏课表页面缩短 40%+。
- `--van-nav-bar-height: 58px` 补进 `:root` → 修复吸顶表头错位及所有依赖该变量的计算。
- 空白格"＋"在触屏给常驻低透明度（或仅今日列），保留 hover 全亮。
- **零课程空状态**用 SemesterGate 同款手绘插画重做，并排「导入课表」（主）+「手动添加」（次）双 CTA——新用户激活关键界面。
- 加**当前时刻高亮**（今日列 × 当前节次柔和呼吸描边）+ 左右滑动切周手势（复用现有方向过渡）+ `needs_location_review` 微徽标。
- 周切换过渡去掉 `filter:blur`（低端 Android 掉帧源），只保留位移+透明度。

**地图 / 消息**：
- 地图**标记可见化**：非选中建筑渲染 8-10px 叶形可见 pin，命中区 ≥32px 与 pin 同心 → 解决"看不见哪里能点"的核心问题。
- 消息流**重构为单滚动区**：去掉 `.message-list` 内滚 `max-height`，页面自然滚动 + nav sticky + composer fixed；"看更早留言"记录锚点做 `scrollTop` 补偿 → 一次解决双滚动 + 跳动两个高优。
- 作者色点改 `display_name` **哈希取色**，可升级为 24px 首字头像圆。
- 留言时间戳**按日分组**（今天 / 昨天 / MM-DD 分隔条），行内只留 `HH:mm`。
- 统一地图点击行为为"点选出卡、卡上确认跳转"，让 `selected-card` 真正发挥防误触作用。
- 地图错误文案分层：用户看"地图暂时打不开，稍后再试"，Key/白名单开发提示仅 `import.meta.env.DEV` 显示。

### 阶段 2 · 认证与个人流程打磨

- **会话过期内联提示**：LoginPage 读 `route.query.reason === 'expired'`，登录卡顶部渲染品牌一致的温和纸条（"登录状态过期了，重新登录就好"），比 toast 更不易错过。
- **登录改乐观导航**：成功即 `router.replace`，`prepareLoginIntro` 后台执行；删掉登录页成功 toast，让首页欢迎卡成为唯一欢迎反馈（消除双重反馈）。
- **过场卡升级为可交互入口**：有课程快照时点按跳当天课表/该楼路线；离场用 `grid-template-rows: 1fr→0fr` 动画收起高度，消除 90px 跳动；时长按文本长度或改为点按关闭。
- **个人页 hero footer 换真实数据**：本学期课程数（coursesStore 已有）、留言参与数、常去建筑；删除与账号列表重复的"身份"格。
- **编辑资料改底部弹层**（`van-popup round position=bottom`）消除文档流跳动；头像色板实时预览（编辑态读 `profileForm`）。
- 密码框加 show/hide 切换（`right-icon=eye-o`）；退出登录加 `showConfirmDialog` 二次确认；注册链路透传 `redirect`；触控目标对齐 44px 标准。

### 阶段 3 · 动效体系统一 + animejs 收口

- **动效统一到 `v-reveal` + 弹簧缓动一套**：HomePage 的 animejs 进场改用 `v-reveal`，欢迎卡 keyframes 并入统一节奏 → 消除首页数据到达后的二次闪现（进场机制不一致导致）。
- **路由转场提速 + 方向感知**：时长压到 280-350ms；按路由深度左右滑（前进/后退有层级方向）；tab 间切换仅 fade 或禁转场。
- **animejs 二选一收口**：要么以 fresh 视觉复活一段轻量登录欢迎时间线（`loginIntro.ts` 快照机器完好可复用），要么**删除 animejs 依赖 + 孤儿代码**（`shouldPlayAppLaunchIntro`、handoff CSS）改纯 CSS。当前"为一处 stagger 背一个库+一份 spec"是最差状态。推荐后者（更轻），如需仪式感则前者。

### 阶段 4 · 组件沉淀与文档同步

- 抽 **`BuildingPicker`**（搜索 + 过滤 chips/列表）统一表单页 / 导入卡 / 出发页三处建筑选择（导入页几十栋楼场景收益最大）。
- 封装 **`goBack(fallbackPath)`**（优先 `history.back`），杜绝 push 式返回撑爆历史栈。
- **图标语言归一**：pages 中 16 种 van-icon 迁入 TechIcon 体系（统一 1.55 描边圆头），TechIcon 加 name 枚举。
- **术语表统一**：全域"地点频道 / 教室频道"，替换"建筑总聊"，复查所有 nav 标题。
- **文档回写**：`SCREENSHOT_CHECKLIST`（删已移除的启动动画条目、补纵向课表/学期设置/无损导入截图项）、`TECHNICAL_HIGHLIGHTS`（更新测试基线数与页面表）——这些是答辩/简历材料，失真有实际代价。

## 四、建议执行顺序与工作量预估

```
阶段 0（地基）      ██████  高杠杆 · 必须先做 · 约 1-1.5 天
阶段 1（核心页）    ████████  体感提升最大 · 约 2 天
阶段 2（认证个人）  █████  约 1-1.5 天
阶段 3（动效收口）  ███  约 1 天
阶段 4（组件文档）  ████  约 1 天
```

- **若时间有限，优先级 TOP 5**（单点体感最高）：① 阶段 0 令牌合并 + 字体上线；② 课表色块哈希调色板 + 爆行修复；③ 消息页单滚动区重构；④ 地图标记可见化；⑤ 会话过期内联提示 + 登录乐观导航。
- 每阶段结束跑 `npm test` + `npm run build` + 双视口 e2e，把对比度/视口断言作为发布门槛，视觉改动始终有回归保护网。

## 五、明确不做（避免范围蔓延）

- **暗色模式**：当前 517 处硬编码是唯一真正阻断项；阶段 0 令牌收敛完成后，暗色仅需 `[data-theme=dark]` 翻转一套令牌，届时再评估，本轮不做。
- **实时聊天**（WebSocket 推送）：消息页现为地理围栏留言板形态，轻量轮询（15s）或下拉刷新已足够"活人感"，实时化超出本轮范围。
- **推翻清新自然方向**：所有改动均在既有令牌体系上扩展，不引入第二套视觉语言。

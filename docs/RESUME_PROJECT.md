# 简历项目说明

## 项目名称

智行 CampusMind

## 一句话介绍

基于 Vue 3 + FastAPI 的手机端智慧校园系统，面向湖北大学学生提供真实校园地图、建筑/教室匿名会话、课程表导入、出发建议和定位约束留言能力。

## 简历可用版本

### 简洁版

智行 CampusMind：独立设计并实现手机端智慧校园 H5/PWA，使用 Vue 3、Vant UI、Pinia、FastAPI、SQLAlchemy 和 SQLite 完成用户认证、真实校园地图、建筑/教室聊天室、课程表 CRUD 与 HTML/Excel 导入、出发建议和定位约束留言；接入高德地图 JS API，实现校园点位搜索、路线预览和移动端交互优化；编写 pytest/Vitest 测试，后端 61 个用例、前端 81 个用例通过。

### 详细版

- 负责项目从需求收敛、MVP 范围设计、前后端架构到功能实现和交付文档整理的完整流程。
- 后端基于 FastAPI + SQLAlchemy + SQLite 设计 users、buildings、messages、courses 等核心模型，实现 JWT 登录、建筑数据、建筑聊天室、课程 CRUD、课表导入预览和出发建议 API。
- 前端基于 Vue 3 + Vite + TypeScript + Vant UI 实现手机端 H5/PWA，包含登录注册、真实校园地图、建筑详情、教室聊天室、课程表、出发建议、个人资料编辑和启动动效。
- 接入高德地图 JS API，实现校园范围内点位展示、搜索、缩放分层、Walking 路线预览，并在定位失败或路线失败时提供可用兜底。
- 实现 HTML/Excel 课表导入，解析课程名、教师、周次、节次、教室，并根据校园地点数据自动匹配建筑，降低手动录入成本。
- 引入定位约束留言：用户未定位或距离目标建筑过远时禁用输入，并给出中文提示，后端仍保留距离校验。
- 建立测试与交付文档体系，覆盖后端 61 个 pytest 用例、前端 81 个 Vitest 用例和构建验证。

## 面试讲解重点

### 1. 为什么这个项目不是简单 CRUD

项目不是只做登录和表单，而是把“课程表、地图、建筑会话、定位、路线建议”串成一个校园生活场景闭环。用户可以从地图找地点，从地点进入聊天室，再把课程地点用于出发建议。

### 2. 最能体现工程能力的部分

- **功能拆分**：先做认证、建筑、留言、课程，再做路线建议，避免一次性堆功能。
- **数据建模**：建筑、课程、留言和用户之间关系清晰，课程和留言都按当前登录用户隔离。
- **地图集成**：高德地图加载、Key 配置、路线规划失败兜底、校园点位搜索和缩放分层都做了工程处理。
- **导入能力**：HTML/Excel 课表导入把非结构化课表转成课程数据，并做建筑自动匹配。
- **体验细节**：移动端布局、周次筛选、课程表网格、固定返回入口、定位提示、不可发言状态都围绕真实使用场景优化。
- **质量保障**：后端和前端都有自动化测试，提交前以测试和构建作为验收标准。

### 3. 可以主动说明的取舍

- 当前使用项目内账号 + JWT，真实湖北大学统一身份认证作为后续扩展。
- 留言为 HTTP 模式，不做 WebSocket，是为了先保证频道、定位和权限规则正确。
- 路线预览依赖高德地图网络和 Key；路线失败时前端会展示可理解提示并保留主流程。
- SQLite 适合课程设计 MVP，后续可迁移到 PostgreSQL 或 MySQL。

## 30 秒口头介绍

我做了一个叫智行 CampusMind 的智慧校园 H5/PWA，主要解决学生找地点、看课程、出发和建筑交流的问题。前端用 Vue 3 + Vant UI，后端用 FastAPI + SQLite。项目接入了高德地图，可以展示湖北大学校园点位和路线预览；课程表支持 HTML/Excel 导入；建筑可以进入总聊天室或具体教室聊天室；留言时会做定位限制。项目不是静态 demo，前后端接口、数据库、测试和运行文档都完整，后端 61 个测试、前端 81 个测试通过。

# 12_四周开发计划：4周开发计划

## 1. 总体安排

项目周期：4 周
开发人数：1 人
目标：完成可运行 MVP 并能部署测试

## 2. 第 1 周：需求、设计、环境搭建

### 第 1 天

任务：

1. 确定项目名称。
2. 确定 MVP 范围。
3. 编写项目简介。
4. 创建 Git 仓库。

产物：

```text
00_文档目录与使用说明.md
项目立项说明
```

### 第 2 天

任务：

1. 编写需求分析。
2. 确定功能列表。
3. 确定用户角色。

产物：

```text
需求分析说明书
```

### 第 3 天

任务：

1. 设计页面原型。
2. 设计用户流程。
3. 确定页面路由。

产物：

```text
页面原型图
用户流程图
```

### 第 4 天

任务：

1. 设计数据库表。
2. 设计 E-R 图。
3. 准备建筑初始数据。

产物：

```text
数据库设计文档
建筑点位表
```

### 第 5 天

任务：

1. 搭建 FastAPI 后端。
2. 搭建 Vue 前端。
3. 配置开发环境。

产物：

```text
backend 项目
frontend 项目
```

### 第 6-7 天

任务：

1. 完成数据库模型。
2. 完成基础接口结构。
3. 整理第 1 周文档。

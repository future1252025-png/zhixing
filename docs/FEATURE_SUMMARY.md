# 功能总结

## 用户认证

- 支持注册、登录、获取当前用户和退出登录。
- 后端使用 JWT 鉴权。
- 第一版使用模拟校园账号，不接真实湖北大学统一身份认证。

## 校园建筑

- 首页展示校园建筑列表。
- 建筑详情展示建筑类型、简介、经纬度、静态地图坐标和步行提示。
- 位置预设用于演示当前位置选择。

## 建筑留言

- 每个建筑有独立留言区。
- 留言使用 HTTP 读取和发布。
- 发布留言需要登录。
- 留言统一显示为“匿名同学”。

## 课程表

- 当前登录用户可以维护自己的课程。
- 支持新增、编辑、删除课程。
- 课程包含名称、星期、上下课时间、建筑、教室、教师和周次。
- 课程列表按星期分组展示。

## 出发建议

- 后端根据当前用户未来最近一节课生成建议。
- 支持从建筑或经纬度作为当前位置。
- 距离使用经纬度直线估算。
- 步行速度按 80 米/分钟估算。
- 默认预留 10 分钟缓冲时间。
- 返回 normal、tight、likely_late 三档状态。

## 路径可视化

- 前端 Schedule 页面展示起点、终点、距离、步行时间、缓冲时间和建议出发时间。
- 使用静态点线方式显示“当前位置 -> 目标建筑”。
- 第一版不接真实地图 SDK，不做真实路线导航。

## 后续扩展

- 接入湖北大学统一身份认证。
- 增加 WebSocket 实时留言。
- 增加管理员内容治理。
- 接入真实地图 SDK。
- 加入 AI 智能建议和推送提醒。

# 02_项目概述：项目概述

## 1. 项目名称

湖大智行 CampusMind

## 2. 项目背景

湖北大学学生在日常校园生活中经常需要在教学楼、图书馆、食堂、宿舍、体育馆等地点之间移动。学生常见问题包括：

1. 不清楚当前地点到下一节课地点需要多久。
2. 不知道什么时候应该出发才不会迟到。
3. 不清楚食堂排队、图书馆座位、教学楼临时情况等现场信息。
4. 新生或不熟悉校园的学生难以快速找到建筑。
5. 校园信息分散在班级群、社团群、公众号、口头传播中，信息差明显。

因此，本项目希望把校园地图、地点聊天室和日程规划结合起来，构建一个适合湖北大学学生使用的校园服务系统。

## 3. 项目目标

建设一个基于湖北大学真实校园场景的 Web 系统，实现：

1. 以卡通化校园地图作为首页入口。
2. 学生可以点击具体建筑查看建筑信息。
3. 每个建筑拥有一个匿名聊天室。
4. 只有处于建筑附近的学生可以在该建筑聊天室发言。
5. 不在建筑附近的学生可以查看消息，但不能发言。
6. 学生可以手动录入课程表。
7. 系统根据课程时间、地点距离和当前位置生成出发建议。
8. 系统提供上课提醒和出发提醒。
9. 管理员可以维护建筑信息、管理聊天内容。

## 4. 目标用户

### 4.1 学生用户

主要使用者。功能包括：

- 登录系统。
- 查看校园地图。
- 查看建筑信息。
- 查看建筑聊天室。
- 在当前位置附近的建筑聊天室发言。
- 管理个人课程表。
- 查看路线时间建议。
- 接收提醒。

### 4.2 管理员

维护系统内容。功能包括：

- 管理建筑信息。
- 管理建筑频道。
- 查看和处理举报。
- 隐藏或删除违规消息。
- 维护系统基础数据。

## 5. 项目特色

1. 地图化入口：以校园空间组织信息。
2. 建筑级位置聊天室：每个建筑都有独立信息区。
3. 位置限定发言：提高现场信息真实性。
4. 匿名但可追溯：前台匿名，后台保留用户 ID。
5. 课程驱动日程规划：结合课程表和建筑位置给出出发建议。
6. 可扩展智慧校园入口：后续可接入食堂排队、图书馆座位、校园活动等服务。

## 6. 第一版边界

第一版只做 MVP：

- 做建筑级定位，不做室内精确定位。
- 做模拟登录，不接入真实校园统一身份认证。
- 做规则算法，不接入复杂 AI 大模型。
- 做主要建筑，不录入全校全部地点。
- 做 Web 端，不做原生 App。

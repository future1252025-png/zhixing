# 06_数据库设计：数据库设计

## 1. 数据库选择

第一版使用 SQLite，方便开发和部署。
后续正式上线可迁移到 MySQL。

## 2. 数据表列表

```text
user              用户表
building          建筑表
room_channel      建筑内频道表
message           聊天消息表
course            课程表
reminder          提醒表
report            举报表
```

## 3. user 用户表

| 字段名 | 类型 | 说明 |
|---|---|---|
| id | Integer | 主键 |
| student_id | String | 学号，唯一 |
| username | String | 用户名 |
| password_hash | String | 加密密码 |
| nickname | String | 昵称 |
| role | String | student/admin |
| created_at | DateTime | 创建时间 |

## 4. building 建筑表

| 字段名 | 类型 | 说明 |
|---|---|---|
| id | Integer | 主键 |
| name | String | 建筑名称 |
| type | String | 建筑类型，如教学楼、食堂、图书馆 |
| description | Text | 建筑简介 |
| latitude | Float | 纬度 |
| longitude | Float | 经度 |
| radius | Float | 允许发言半径，单位米 |
| map_x | Float | 卡通地图 x 坐标百分比 |
| map_y | Float | 卡通地图 y 坐标百分比 |
| image_url | String | 建筑图片 |
| created_at | DateTime | 创建时间 |

## 5. room_channel 建筑内频道表

| 字段名 | 类型 | 说明 |
|---|---|---|
| id | Integer | 主键 |
| building_id | Integer | 所属建筑 |
| name | String | 频道名称 |
| description | Text | 频道说明 |
| created_at | DateTime | 创建时间 |

示例频道：

```text
建筑总频道
101教室
201教室
一楼大厅
自习区
食堂一楼
食堂二楼
```

## 6. message 聊天消息表

| 字段名 | 类型 | 说明 |
|---|---|---|
| id | Integer | 主键 |
| user_id | Integer | 发送者 ID |
| building_id | Integer | 建筑 ID |
| channel_id | Integer | 频道 ID |
| content | Text | 消息内容 |
| status | String | normal/hidden/deleted/reported |
| created_at | DateTime | 创建时间 |

## 7. course 课程表

| 字段名 | 类型 | 说明 |
|---|---|---|
| id | Integer | 主键 |
| user_id | Integer | 用户 ID |
| course_name | String | 课程名称 |
| weekday | Integer | 星期，1-7 |
| start_time | String | 开始时间，如 08:00 |
| end_time | String | 结束时间，如 09:40 |
| building_id | Integer | 上课建筑 |
| room_name | String | 教室 |
| teacher | String | 教师 |
| weeks | String | 周次，如 1-16 |
| created_at | DateTime | 创建时间 |

## 8. reminder 提醒表

| 字段名 | 类型 | 说明 |
|---|---|---|
| id | Integer | 主键 |
| user_id | Integer | 用户 ID |
| course_id | Integer | 课程 ID |
| remind_time | DateTime | 提醒时间 |
| content | Text | 提醒内容 |
| status | String | pending/sent/cancelled |
| created_at | DateTime | 创建时间 |

## 9. report 举报表

| 字段名 | 类型 | 说明 |
|---|---|---|
| id | Integer | 主键 |
| message_id | Integer | 被举报消息 |
| reporter_id | Integer | 举报人 |
| reason | Text | 举报原因 |
| status | String | pending/processed/rejected |
| created_at | DateTime | 创建时间 |

## 10. 初始数据建议

第一版可以手动插入建筑数据。坐标和地图位置允许后续微调。

```text
图书馆
一号教学楼
二号教学楼
三号教学楼
逸夫楼
实验楼
一食堂
二食堂
体育馆
学生宿舍区
校医院
行政楼
```

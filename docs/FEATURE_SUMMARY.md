# 当前功能

## 账号与个人中心

- 注册、登录、短期 JWT 鉴权、30 天刷新会话轮换、退出吊销和登录过期处理。
- 昵称、头像等个人资料编辑。
- 受保护页面路由守卫和登录重定向。

## 核心特色：地点聊天室与校园地图

- 湖北大学武昌校区真实地图与校园点位。
- 地点搜索、缩放分层、点位选中和步行路线预览。
- 地点名称清洗，移动端优先展示具体名称。
- 每个校园建筑对应一个公共地点聊天室；可信教务课表识别出的教室可形成独立教室聊天室。
- 可从地图点位、地点搜索和课程地点进入对应聊天室，查看分频道留言与消息数量。
- 聊天室统一匿名展示；发布包含频率限制、重复内容冷却和游标分页支持。
- 用户主动定位和距离校验；距离过远、定位过旧或精度不足时只允许查看。
- 精确经纬度只用于后端发布校验，不写入留言记录；仅保留核验后的距离结果。

## 课程表

- 学期起始日期和总周数设置。
- 课程新增、编辑、删除与完整周课表。
- 教师、地点、节次、单双周和自定义周次展示。
- HTML、Excel 与 Android 教务系统导入。
- 整批导入覆盖旧课表；单条缺失或解析失败不阻断其余课程。
- 课程地点允许保留教务原文，路线需要时再补全地图匹配。

## 出发建议

- 使用当前定位、搜索地点或校园点位作为起点。
- 使用下一节课地点或手动选择地点作为终点。
- 展示课程、时间、缓冲、出发状态和高德步行路线。

## Android

- Capacitor Android App。
- 系统原生定位权限与融合定位。
- 内置湖北大学教务系统登录和课表提取。
- 刘海屏、状态栏、底部手势区和移动端表单适配。

## 质量保障

- pytest 后端回归测试。
- Vitest 前端组件、状态和工具测试。
- Playwright 桌面/手机核心用户旅程。
- Android JUnit 与 APK 构建验证。

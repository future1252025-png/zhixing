# 11_页面与交互设计：页面与交互设计

## 1. 页面总览

```text
登录页
注册页
校园地图首页
建筑详情页
建筑聊天室页
课程表页
日程建议页
管理员后台页
```

## 2. 登录页

## 2.1 页面元素

```text
项目名称：智行 CampusMind
用户名输入框
密码输入框
登录按钮
注册入口
```

## 2.2 交互

1. 用户输入用户名和密码。
2. 点击登录。
3. 登录成功后跳转地图首页。
4. 登录失败时显示错误提示。

---

## 3. 校园地图首页

## 3.1 页面元素

```text
顶部标题栏
卡通校园地图
建筑点位
底部导航栏
```

## 3.2 建筑点显示内容

```text
建筑名称
建筑类型图标
```

## 3.3 交互

1. 点击建筑点。
2. 跳转建筑详情页。
3. 点击底部课程表进入课程表页面。
4. 点击底部日程进入日程建议页面。

---

## 4. 建筑详情页

## 4.1 页面元素

```text
建筑图片
建筑名称
建筑类型
建筑简介
建筑频道列表
进入聊天室按钮
返回地图按钮
```

## 4.2 交互

1. 点击建筑总频道进入聊天室。
2. 点击具体频道进入对应频道聊天室。

---

## 5. 聊天室页

## 5.1 页面元素

```text
顶部建筑名称
频道名称
定位状态提示
消息列表
消息输入框
发送按钮
举报按钮
```

## 5.2 状态一：允许发言

显示：

```text
你当前在该建筑附近，可以发言
```

输入框可用。

## 5.3 状态二：不允许发言

显示：

```text
你当前不在该建筑范围内，仅可查看消息
```

输入框禁用。

## 5.4 消息样式

```text
匿名同学
12:30
三楼还有空位
```

---

## 6. 课程表页

## 6.1 页面元素

```text
课程列表
添加课程按钮
课程名称
星期
开始时间
结束时间
上课建筑
教室
教师
```

## 6.2 交互

1. 添加课程。
2. 修改课程。
3. 删除课程。
4. 选择上课建筑。

---

## 7. 日程建议页

## 7.1 页面元素

```text
当前位置获取按钮
下一节课卡片
目标建筑
预计距离
预计步行时间
建议出发时间
提醒按钮
```

## 7.2 示例显示

```text
下一节课：数据库原理
地点：三号教学楼 302
上课时间：10:10
当前位置距离：650 米
预计步行：9 分钟
缓冲时间：5 分钟
建议出发：09:56
```

---

## 8. 管理员后台页

## 8.1 页面元素

```text
建筑管理
消息管理
举报管理
```

## 8.2 建筑管理

功能：

1. 新增建筑。
2. 修改建筑。
3. 删除建筑。

## 8.3 消息管理

功能：

1. 查看消息。
2. 隐藏消息。
3. 删除消息。

## 8.4 举报管理

功能：

1. 查看举报。
2. 处理举报。
3. 驳回举报。

---

## 9. 底部导航建议

```text
地图
课程
日程
我的
```

第一版“我的”页面可以不做或只显示用户信息和退出登录。

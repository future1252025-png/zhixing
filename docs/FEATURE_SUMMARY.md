# 功能总结

## 用户认证与个人资料

- 支持注册、登录、获取当前用户和退出登录。
- 后端使用 JWT 鉴权。
- 支持编辑昵称和头像信息。
- 当前版本使用项目内账号体系，真实湖北大学统一身份认证作为后续扩展。

## 真实校园地图

- 首页接入高德地图 JS API。
- 支持湖北大学武昌校区校园点位展示。
- 支持地点搜索、地图缩放和点位分层展示。
- 支持地图采点辅助能力，方便补充高德搜索不到的校内细地点。

## 建筑与教室会话

- 用户可从地图或搜索结果进入建筑详情。
- 建筑详情可进入聊天室选择页。
- 聊天室包括建筑总频道和具体教室频道。
- 留言统一显示为“匿名同学”，数据库保留真实用户关联。
- 留言通过 HTTP 读取和发布，当前版本不做 WebSocket 实时广播。

## 留言定位限制

- 发布留言前需要获取用户当前位置。
- 支持浏览器/高德定位。
- 如果用户距离目标建筑过远，前端直接禁用输入框，并给出中文提示。
- 后端保留距离校验，避免绕过前端限制。

## 课程表

- 当前登录用户可以维护自己的课程。
- 支持新增、编辑、删除课程。
- 课程包含名称、星期、时间、建筑、教室、教师和周次。
- 课程表采用整周网格视图，支持周次切换。
- 支持 HTML/Excel 课表导入预览，并尽量自动匹配建筑。

## 出发建议

- 后端根据当前用户未来最近课程生成建议。
- 起点和终点都支持搜索选择。
- 终点不选择时，默认使用下一节课地点。
- 返回下一节课、起点、终点、步行时间、缓冲时间、建议出发时间和状态提示。

## 路线预览

- 前端出发建议页使用高德地图展示路线预览。
- 当前版本聚焦校园步行参考，不做复杂室内导航。
- 路线失败时给出提示，并保持主流程可用。

## UI 与动效

- 手机端 H5/PWA 布局。
- 使用 Vant UI 搭建移动端交互。
- 使用 animejs 制作登录后启动动效。
- 针对返回入口、底部导航、课程表密度和地图搜索做了移动端优化。

## 后续扩展

- 接入湖北大学统一身份认证。
- 增加 WebSocket 实时留言。
- 增加管理员内容治理、举报和隐藏消息能力。
- 增加推送通知。
- 接入更完整的校园路径和室内定位能力。
- 引入 AI 做课表识别、路线解释和个性化提醒。
